# Kế hoạch làm trang web (trang dùng và đưa lên mạng)

> **Cho người thực hiện (agent):** dùng superpowers:subagent-driven-development (khuyên dùng) hoặc superpowers:executing-plans để làm theo từng task. Các bước dùng ô `- [ ]` để đánh dấu.
>
> **Cần làm xong kế hoạch API trước** (`docs/ke-hoach/2026-10-09-api.md`): trang này sinh code gọi từ `app/api/openapi.json` và kiểm thử với API chạy trong Docker.

**Goal:** trang `/xem` (xem lưới ảnh, mở bài, đăng ảnh, nhãn trạng thái cụm) trong cùng trang web với trang giới thiệu, dựng tĩnh bằng Astro và Svelte, kiểm thử bằng trình duyệt tự động, và tự đăng lên `dr.qivarn.id.vn` qua kho `dr-preview` khi `main` qua hết kiểm tra.

**Architecture:** `app/web` là một dự án Astro xuất trang tĩnh. Trang giới thiệu giữ nguyên trong `public/` (chỉ thêm đoạn chuyển hướng và nút "Vào xem"). `/xem` là một đảo Svelte: thư viện thuần (`src/lib`) lo trạng thái cụm, xếp lưới, nén ảnh, lưu trữ trên máy, kính lỏng; các component Svelte chỉ ghép chúng lại. Code gọi API sinh từ OpenAPI. `ci` dựng, kiểm thử bằng Playwright với API thật trong Docker, đo Lighthouse, rồi đẩy bản dựng sang `dr-preview`.

**Tech Stack:** Node 24, Astro 7.3.8, Svelte 5.57.2, @astrojs/svelte 9.0.1, @tanstack/svelte-query 6.3.1, openapi-typescript 7.13.0, openapi-fetch 0.17.0, TypeScript 5.9.3, Vitest 5.0.3, Playwright 1.64.0, @axe-core/playwright 4.13.0, @lhci/cli 0.15.1.

**Spec:** [`docs/thiet-ke-web.md`](../thiet-ke-web.md) mục 1, 3, 4, 5.

## Global Constraints

- Phông Be Vietnam Pro từ Google Fonts, nền đen, các biến màu và lớp `.glass` lấy đúng từ trang giới thiệu. Trang `/xem` không tải Three.js.
- Đường dẫn: `/` trang giới thiệu, `/xem/` trang dùng, một bài là `/xem/?bai={id}`, xem lại giới thiệu là `/?gioi-thieu`.
- Khóa `localStorage`: `ma-bi-mat` (mã đăng bài), `da-vao-xem` (`"1"` khi đã bấm Vào xem). Mọi đọc ghi bọc `try/catch`.
- Nhãn trạng thái: gọi `/healthz` mỗi 5 giây (2 giây khi sự cố), chờ tối đa 3 giây, dừng khi tab ẩn; hai lần lỗi liên tiếp mới chuyển sang sự cố.
- Ảnh gửi đi luôn được mã hóa lại trong trình duyệt: cạnh dài tối đa 2560 px, WebP chất lượng 0,85 giảm dần tới khi không quá 1 048 576 byte; không ghi được WebP thì dùng JPEG.
- `idempotency_key` tạo một lần cho mỗi lần bấm Đăng, giữ nguyên khi thử lại.
- Lighthouse `/xem/` cấu hình điện thoại: hiệu năng ≥ 0,95. axe: không có lỗi mức `serious` hoặc `critical`.
- Biến dựng: `PUBLIC_API_URL`, `PUBLIC_API_READY` (`true` mới mở trang dùng).
- Không viết chú thích trong code (quy tắc của kho).

## Review Focus

- **Mở `/xem/` khi API đang chết:** trang không trắng xóa; nhãn chuyển vàng, có lời nhắn chưa tải được ảnh, và tự tải khi API có lại. Kiểm ở Task 4 (`su-co.spec.ts` mở trang trong lúc API còn sống rồi tắt; Task 4 Step 6 thêm trường hợp mở trang khi API đã tắt).

- **Ảnh điện thoại vài MB, ảnh xoay dọc:** tự nén dưới 1 MiB, giữ đúng chiều. Kiểm ở Task 5.

```ts
import createClient from 'openapi-fetch';

import type { components, paths } from './schema';

export type Bai = components['schemas']['Post'];
export type TrangBai = components['schemas']['PostPage'];
export type SucKhoe = components['schemas']['Health'];

export interface KetQuaDang {
  trangThai: number;
  bai?: Bai;
  loi?: { error: string; message: string };
}

export function taoMayKhach(goc: string) {
  return createClient<paths>({ baseUrl: goc });
}

export const urlAnh = (goc: string, id: string): string => `${goc}/v1/posts/${id}/image`;
export const urlAnhNho = (goc: string, id: string): string => `${goc}/v1/posts/${id}/thumbnail`;

export async function kiemTraMa(goc: string, ma: string): Promise<number> {
  try {
    const r = await fetch(`${goc}/v1/secret-code/verify`, { method: 'POST', headers: { Authorization: `Bearer ${ma}` } });
    return r.status;
  } catch {
    return 0;
  }
}

export function dangBai(
  goc: string,
  ma: string,
  du: { maLanDang: string; tieuDe: string; moTa: string; anh: Blob },
  tienDo: (phan: number) => void,
): Promise<KetQuaDang> {
  return new Promise((xong) => {
    const form = new FormData();
    form.append('idempotency_key', du.maLanDang);
    form.append('title', du.tieuDe);
    form.append('description', du.moTa);
    form.append('image', du.anh, du.anh.type === 'image/jpeg' ? 'image.jpg' : 'image.webp');
    const x = new XMLHttpRequest();
    x.open('POST', `${goc}/v1/posts`);
    x.setRequestHeader('Authorization', `Bearer ${ma}`);
    x.timeout = 60_000;
    x.upload.onprogress = (e) => {
      if (e.lengthComputable) tienDo(e.loaded / e.total);
    };
    x.onload = () => {
      let than: unknown = null;
      try {
        than = JSON.parse(x.responseText);
      } catch {
        than = null;
      }
      if (x.status === 200 || x.status === 201) {
        xong({ trangThai: x.status, bai: than as Bai });
        return;
      }
      const loi = (than as KetQuaDang['loi']) ?? { error: 'unavailable', message: 'Không gửi được, thử lại sau.' };
      xong({ trangThai: x.status, loi });
    };
    const matMang = () => xong({ trangThai: 0, loi: { error: 'network', message: 'Mất kết nối, thử lại.' } });
    x.onerror = matMang;
    x.ontimeout = matMang;
    x.send(form);
  });
}
```

`app/web/src/lib/trang-thai.ts`:

```ts
export type TrangThai =
  | { loai: 'dang-kiem' }
  | { loai: 'on'; cum: string; vung: string; chiDoc: boolean }
  | { loai: 'su-co'; tuLuc: number };

export type SuKien =
  | { loai: 'thanh-cong'; cum: string; vung: string; chiDoc: boolean; luc: number }
  | { loai: 'that-bai'; luc: number };

export interface May {
  trangThai: TrangThai;
  loiLienTiep: number;
  loiDauTien: number | null;
  thongBao: string | null;
}

export const mayMoi = (): May => ({ trangThai: { loai: 'dang-kiem' }, loiLienTiep: 0, loiDauTien: null, thongBao: null });

export function dinhDangKhoang(ms: number): string {
  const giay = Math.max(0, Math.round(ms / 1000));
  const phut = Math.floor(giay / 60);
  return phut > 0 ? `${phut} phút ${giay % 60} giây` : `${giay} giây`;
}

export function buoc(m: May, s: SuKien): May {
  if (s.loai === 'that-bai') {
    const loiDauTien = m.loiDauTien ?? s.luc;
    const loiLienTiep = m.loiLienTiep + 1;
    const trangThai: TrangThai = loiLienTiep >= 2 ? { loai: 'su-co', tuLuc: loiDauTien } : m.trangThai;
    return { trangThai, loiLienTiep, loiDauTien, thongBao: m.thongBao };
  }
  const thongBao = m.trangThai.loai === 'su-co' ? `Đã chạy lại sau ${dinhDangKhoang(s.luc - m.trangThai.tuLuc)}` : m.thongBao;
  return { trangThai: { loai: 'on', cum: s.cum, vung: s.vung, chiDoc: s.chiDoc }, loiLienTiep: 0, loiDauTien: null, thongBao };
}

export const boThongBao = (m: May): May => ({ ...m, thongBao: null });

export const khoangCach = (m: May): number => (m.trangThai.loai === 'su-co' ? 2000 : 5000);

const TEN_VUNG: Record<string, string> = { koreacentral: 'Hàn Quốc', japanwest: 'Nhật Bản' };

export function nhan(t: TrangThai): { chu: string; mau: 'xanh' | 'vang' | 'xam' } {
  if (t.loai === 'dang-kiem') return { chu: 'Đang kiểm tra…', mau: 'xam' };
  if (t.loai === 'su-co') return { chu: 'Đang khôi phục…', mau: 'vang' };
  const cum = t.cum === 'primary' ? 'Cụm chính' : 'Cụm dự phòng';
  const vung = TEN_VUNG[t.vung] ?? t.vung;
  return { chu: vung ? `${cum} · ${vung}` : cum, mau: 'xanh' };
}
```

```ts
export interface OAnh {
  id: string;
  rong: number;
  cao: number;
}

export interface ONhap {
  id: string;
  x: number;
  y: number;
  rong: number;
  cao: number;
}

export function xepLuoi(ds: OAnh[], beRong: number, caoMucTieu: number, khoang: number, chu: number): { o: ONhap[]; caoTong: number } {
  const o: ONhap[] = [];
  let y = 0;
  let hang: OAnh[] = [];
  let tongTiLe = 0;
  const dong = (cao: number) => {
    let x = 0;
    for (const a of hang) {
      const rong = (a.rong / a.cao) * cao;
      o.push({ id: a.id, x, y, rong, cao });
      x += rong + khoang;
    }
    y += cao + chu + khoang;
    hang = [];
    tongTiLe = 0;
  };
  for (const a of ds) {
    hang.push(a);
    tongTiLe += a.rong / a.cao;
    if (tongTiLe * caoMucTieu + khoang * (hang.length - 1) >= beRong) {
      dong((beRong - khoang * (hang.length - 1)) / tongTiLe);
    }
  }
  if (hang.length) dong(Math.min(caoMucTieu, (beRong - khoang * (hang.length - 1)) / tongTiLe));
  return { o, caoTong: Math.max(0, y - khoang) };
}

export function caoMucTieu(beRong: number): number {
  return beRong < 600 ? Math.round((beRong - 8) / 2 / 1.33) : 240;
}
```

```ts
export const CANH_TOI_DA = 2560;
const CAC_CHAT_LUONG = [0.85, 0.75, 0.65, 0.55, 0.45];

export type MaHoa = (rong: number, cao: number, chatLuong: number) => Promise<Blob>;

export function kichThuocMoi(rong: number, cao: number, canh = CANH_TOI_DA): [number, number] {
  const tiLe = Math.min(1, canh / Math.max(rong, cao));
  return [Math.max(1, Math.round(rong * tiLe)), Math.max(1, Math.round(cao * tiLe))];
}

export async function nenVuaGioiHan(rong: number, cao: number, maHoa: MaHoa, gioiHan = BYTE_TOI_DA): Promise<Blob> {
  let [r, c] = kichThuocMoi(rong, cao);
  for (let lan = 0; lan < 6; lan++) {
    for (const q of CAC_CHAT_LUONG) {
      const b = await maHoa(r, c, q);
      if (b.size <= gioiHan) return b;
    }
    [r, c] = [Math.max(1, Math.round(r * 0.8)), Math.max(1, Math.round(c * 0.8))];
  }
  throw new Error('Không nén được ảnh xuống dưới 1 MB.');
}

export async function nenAnh(tep: Blob): Promise<Blob> {
  const anh = await createImageBitmap(tep, { imageOrientation: 'from-image' });
  try {
    let kieu: 'image/webp' | 'image/jpeg' = 'image/webp';
    const maHoa: MaHoa = async (r, c, q) => {
      const canvas = new OffscreenCanvas(r, c);
      const g = canvas.getContext('2d');
      if (!g) throw new Error('Trình duyệt không vẽ được ảnh.');
      g.drawImage(anh, 0, 0, r, c);
      let b = await canvas.convertToBlob({ type: kieu, quality: q });
      if (b.type !== kieu) {
        kieu = 'image/jpeg';
        b = await canvas.convertToBlob({ type: kieu, quality: q });
      }
      return b;
    };
    return await nenVuaGioiHan(anh.width, anh.height, maHoa);
  } finally {
    anh.close();
  }
```

```ts
interface PhanKinh {
  el: HTMLElement;
  bend: number;
  w: number;
  h: number;
  last: string;
  im?: SVGFEImageElement;
  dm?: SVGFEDisplacementMapElement;
  loc?: SVGFilterElement;

let defs: SVGSVGElement | null = null;
let dem = 0;
let px = -1;
let py = -1;
let dangChay = false;

export function giaTriLang(x: number, y: number, hx: number, hy: number, rr: number, band: number): [number, number] {
  const qx = Math.abs(x) - (hx - rr);
  const qy = Math.abs(y) - (hy - rr);
  let nx: number;
  let ny: number;
  let dist: number;
  if (qx > 0 && qy > 0) {
    const l = Math.hypot(qx, qy) || 1;
    dist = rr - l;
    nx = qx / l;
    ny = qy / l;
  } else if (qx > qy) {
    dist = rr - qx;
    nx = 1;
    ny = 0;
  } else {
    dist = rr - qy;
    nx = 0;
    ny = 1;
  }
  nx *= Math.sign(x) || 1;
  ny *= Math.sign(y) || 1;
  const t = Math.max(0, 1 - Math.max(0, dist) / band);
  const m = t * t * (3 - 2 * t);
  return [Math.round(128 - nx * m * 127), Math.round(128 - ny * m * 127)];
}

function banDoLang(w: number, h: number, r: number, band: number): string {
  const k = 0.5;
  const W = Math.max(2, Math.round(w * k));
  const H = Math.max(2, Math.round(h * k));
  const c = document.createElement('canvas');
  c.width = W;
  c.height = H;
  const g = c.getContext('2d');
  if (!g) return '';
  const img = g.createImageData(W, H);
  const d = img.data;
  const hx = w / 2;
  const hy = h / 2;
  const rr = Math.min(r, hx, hy);
  for (let y = 0; y < H; y++) {
    for (let x = 0; x < W; x++) {
      const [vr, vg] = giaTriLang((x + 0.5) / k - hx, (y + 0.5) / k - hy, hx, hy, rr, band);
      const i = (y * W + x) * 4;
      d[i] = vr;
      d[i + 1] = vg;
      d[i + 2] = 128;
      d[i + 3] = 255;
    }
  }
  g.putImageData(img, 0, 0);
  return c.toDataURL();
}

function coKhucXa(): boolean {
  const ud = (navigator as Navigator & { userAgentData?: { brands?: { brand: string }[] } }).userAgentData;
  const brands = ud?.brands?.map((b) => b.brand).join(' ') ?? '';
  return /Chromium|Google Chrome|Microsoft Edge/.test(brands);
}

function dat(el: Element, thuocTinh: Record<string, string>) {
  for (const [k, v] of Object.entries(thuocTinh)) el.setAttribute(k, v);
}

function dinhKich(p: PhanKinh) {
  if (!p.im) return;
  const w = p.el.offsetWidth;
  const h = p.el.offsetHeight;
  if (!w || !h || (w === p.w && h === p.h)) return;
  p.w = w;
  p.h = h;
  const r = parseFloat(getComputedStyle(p.el).borderTopLeftRadius) || h / 2;
  dat(p.im, { width: String(w), height: String(h), href: banDoLang(w, h, Math.min(r, h / 2), Math.min(24, h * 0.42)) });
}

function luot() {
  for (const p of cacPhan) {
    const o = p.el.style.opacity === '' ? 1 : Number(p.el.style.opacity);
    if (p.dm) {
      const s = (p.bend * Math.min(1, o * 1.25)).toFixed(1);
      if (s !== p.last) {
        p.dm.setAttribute('scale', s);
        p.last = s;
      }
    }
    if (px >= 0 && o > 0.05) {
      const r = p.el.getBoundingClientRect();
      p.el.style.setProperty('--gx', `${Math.min(130, Math.max(-30, ((px - r.left) / r.width) * 100)).toFixed(1)}%`);
      p.el.style.setProperty('--gy', `${Math.min(170, Math.max(-70, ((py - r.top) / r.height) * 100)).toFixed(1)}%`);
    }
  }
  if (cacPhan.size) requestAnimationFrame(luot);
  else dangChay = false;
}

export function kinh(el: HTMLElement, tuyChon: { bend?: number; blur?: number } = {}) {
  const p: PhanKinh = { el, bend: tuyChon.bend ?? 28, w: 0, h: 0, last: '' };
  if (coKhucXa()) {
    if (!defs) {
      defs = document.createElementNS(NS, 'svg');
      dat(defs, { width: '0', height: '0', 'aria-hidden': 'true' });
      defs.style.position = 'absolute';
      document.body.prepend(defs);
      addEventListener('pointermove', (e) => {
        px = e.clientX;
        py = e.clientY;
      }, { passive: true });
    }
    const id = `kinh${dem++}`;
    const loc = document.createElementNS(NS, 'filter');
    dat(loc, { id, x: '0', y: '0', width: '100%', height: '100%', 'color-interpolation-filters': 'sRGB' });
    const im = document.createElementNS(NS, 'feImage');
    dat(im, { x: '0', y: '0', preserveAspectRatio: 'none', result: 'map' });
    const dm = document.createElementNS(NS, 'feDisplacementMap');
    dat(dm, { in: 'SourceGraphic', in2: 'map', xChannelSelector: 'R', yChannelSelector: 'G', scale: '0' });
    loc.append(im, dm);
    defs.append(loc);
    Object.assign(p, { im, dm, loc });
    el.style.backdropFilter = `url(#${id}) blur(${tuyChon.blur ?? 4}px) saturate(1.8)`;
  }
  cacPhan.add(p);
  const ro = new ResizeObserver(() => dinhKich(p));
  ro.observe(el);
  dinhKich(p);
  if (!dangChay) {
    dangChay = true;
    requestAnimationFrame(luot);
  }
  return {
    destroy() {
      ro.disconnect();
      cacPhan.delete(p);
      p.loc?.remove();
    },
  };
}
```

```ts
import { crc32, deflateSync } from 'node:zlib';

import type { APIRequestContext } from '@playwright/test';

export const API = process.env.PUBLIC_API_URL ?? 'http://127.0.0.1:8080';
export const MA = process.env.TEST_SECRET_CODE ?? 'test-code-0123456789';

function khoi(loai: string, du: Buffer): Buffer {
  const dai = Buffer.alloc(4);
  dai.writeUInt32BE(du.length);
  const ten = Buffer.from(loai, 'ascii');
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(Buffer.concat([ten, du])) >>> 0);
  return Buffer.concat([dai, ten, du, crc]);
}

export function taoPng(rong: number, cao: number): Buffer {
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(rong, 0);
  ihdr.writeUInt32BE(cao, 4);
  ihdr[8] = 8;
  ihdr[9] = 2;
  const hang = Buffer.alloc(cao * (1 + rong * 3));
  for (let y = 0; y < cao; y++) {
    const o = y * (1 + rong * 3);
    for (let x = 0; x < rong; x++) {
      const i = o + 1 + x * 3;
      hang[i] = x % 256;
      hang[i + 1] = y % 256;
      hang[i + 2] = (x + y) % 256;
    }
  }
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    khoi('IHDR', ihdr),
    khoi('IDAT', deflateSync(hang)),
    khoi('IEND', Buffer.alloc(0)),
  ]);
}

export async function dangQuaApi(request: APIRequestContext, tieuDe: string, rong: number, cao: number): Promise<{ id: string; title: string }> {
  const r = await request.post(`${API}/v1/posts`, {
    headers: { Authorization: `Bearer ${MA}` },
    multipart: {
      idempotency_key: crypto.randomUUID(),
      title: tieuDe,
      description: 'Bài thử tự động',
      image: { name: 'image.png', mimeType: 'image/png', buffer: taoPng(rong, cao) },
    },
  });
  if (r.status() !== 201) throw new Error(`đăng thử lỗi ${r.status()}: ${await r.text()}`);
  return r.json();
}
```

```svelte
  import { type Bai, taoMayKhach, type TrangBai } from '../lib/api/may-khach';
  import { boThongBao, buoc, khoangCach, mayMoi, type SuKien } from '../lib/trang-thai';

  const mk = taoMayKhach(apiUrl);
  const qc = useQueryClient();

  let moDang = $state(false);
  let baiDangXem = $state<string | null>(new URLSearchParams(location.search).get('bai'));

  const ds = createInfiniteQuery(() => ({
    queryKey: ['bai'],
    initialPageParam: null as string | null,
    queryFn: async ({ pageParam }): Promise<TrangBai> => {
      const query = pageParam ? { limit: 24, before: pageParam } : { limit: 24 };
      const { data, error } = await mk.GET('/v1/posts', { params: { query } });
      if (error || !data) throw new Error(error?.message ?? 'Không tải được danh sách.');
      return data;
    },
    getNextPageParam: (trang: TrangBai) => trang.next ?? undefined,
  }));
  const tatCa = $derived(ds.data?.pages.flatMap((p) => p.posts) ?? []);

  async function taiMot(id: string): Promise<Bai | null> {

    return data ?? null;
  }

  $effect(() => {
    let huy = false;
    let hen: ReturnType<typeof setTimeout> | undefined;
    async function kiem() {
      if (huy) return;
      if (document.hidden) {
        hen = setTimeout(kiem, 1000);
        return;
      }
      let sk: SuKien;
      try {
        const r = await fetch(`${apiUrl}/healthz`, { signal: AbortSignal.timeout(3000), cache: 'no-store' });
        const v = await r.json();
        sk = r.ok
          ? { loai: 'thanh-cong', cum: v.cluster, vung: v.region, chiDoc: v.read_only, luc: Date.now() }
          : { loai: 'that-bai', luc: Date.now() };
      } catch {
        sk = { loai: 'that-bai', luc: Date.now() };
      }
      if (huy) return;
      const truocDo = may.trangThai.loai;
      may = buoc(may, sk);
      if (truocDo === 'su-co' && may.trangThai.loai === 'on') qc.invalidateQueries({ queryKey: ['bai'] });
      hen = setTimeout(kiem, khoangCach(may));
    }
    kiem();
    return () => {
      huy = true;
      clearTimeout(hen);
    };
  });

  $effect(() => {
    if (!may.thongBao) return;
    const h = setTimeout(() => (may = boThongBao(may)), 10_000);
    return () => clearTimeout(h);
  });

  $effect(() => {
    const doc = () => (baiDangXem = new URLSearchParams(location.search).get('bai'));
    addEventListener('popstate', doc);
    return () => removeEventListener('popstate', doc);
  });

  function mo(id: string) {
    history.pushState({ bai: id }, '', `?bai=${id}`);
    baiDangXem = id;
  }

  function chuyen(id: string) {
    history.replaceState(history.state, '', `?bai=${id}`);
    baiDangXem = id;
```

```svelte
  import { type Bai, dangBai, kiemTraMa } from '../lib/api/may-khach';
  import { kinh } from '../lib/kinh';
  import { docMa, luuMa, quenMa } from '../lib/luu-tru';
  import { nenAnh } from '../lib/nen-anh';

  let hop: HTMLDialogElement | undefined = $state();

  let maNhap = $state('');

  let xemTruoc = $state<string | null>(null);

    const url = xemTruoc;

      if (url) URL.revokeObjectURL(url);
    };

    e.preventDefault();
    loi = null;
    const nhap = maNhap.trim();
    const s = await kiemTraMa(apiUrl, nhap);
    if (s === 204) {
      luuMa(nhap);
      ma = nhap;
      maNhap = '';

      loi = 'Thử sai quá nhiều lần. Đợi một lúc rồi thử lại.';

      loi = 'Mã không đúng.';
    } else {
      loi = 'Không kiểm tra được mã, thử lại sau.';
    }
  }

  function chon(f: File | null | undefined) {
    if (!f) return;
    if (!f.type.startsWith('image/')) {
      loi = 'Hãy chọn một tệp ảnh.';
      return;
    }
    loi = null;
    tep = f;
    maLanDang = null;
    xemTruoc = URL.createObjectURL(f);
  }

  function boMa() {
    quenMa();
    ma = null;

    e.preventDefault();
    if (!tep || !ma) return;
    loi = null;
    dangGui = true;
    tienDo = 0;
    maLanDang ??= crypto.randomUUID();
    try {
      const anh = await nenAnh(tep);
      const kq = await dangBai(apiUrl, ma, { maLanDang, tieuDe, moTa, anh }, (p) => (tienDo = p));
      if (kq.bai) {
        maLanDang = null;
        onXong(kq.bai);
        hop?.close();
        return;
      }
      if (kq.trangThai === 401) {
        boMa();
        loi = 'Mã đã bị đổi, nhập lại mã.';
      } else {
        loi = kq.loi?.message ?? 'Không đăng được, thử lại.';
      }
    } catch (err) {
      loi = err instanceof Error ? err.message : 'Không xử lý được ảnh.';
    } finally {
      dangGui = false;
      tienDo = null;
    }
  }
```
