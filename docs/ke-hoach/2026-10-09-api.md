# Kế hoạch làm API

> **Cho người thực hiện (agent):** dùng superpowers:subagent-driven-development (khuyên dùng) hoặc superpowers:executing-plans để làm theo từng task. Các bước dùng ô `- [ ]` để đánh dấu.

**Goal:** API JSON bằng Rust cho web đăng ảnh: danh sách, xem bài, ảnh gốc, ảnh nhỏ, đăng bài có mã bí mật, kiểm tra còn sống; chạy với Postgres và kho ảnh Azure Blob hoặc S3; đóng gói thành image nhỏ; kiểm tra tự động trên GitHub Actions.

**Architecture:** một crate `app/api` (thư viện cộng một tệp chạy). Mỗi tệp một việc: cấu hình, lỗi, văn bản, ảnh, mã bí mật, kho ảnh, ảnh nhỏ, cơ sở dữ liệu, trạng thái chung, định tuyến, OpenAPI. Kiểm thử đơn vị nằm trong từng tệp; kiểm thử chạy thật nằm trong `tests/`, chạy với Postgres, Azurite và SeaweedFS trong Docker Compose. `ci` chạy toàn bộ, so OpenAPI, đo image, đẩy image lên GitHub Container Registry khi vào `main`.

**Tech Stack:** Rust 1.97.1 (edition 2024), axum 0.8, tokio 1, sqlx 0.8 (Postgres, macro kiểm tra lúc biên dịch, chế độ offline), object_store 0.12 (Azure, S3), utoipa 5 + utoipa-axum 0.2, image 0.25, fast_image_resize 5, ravif 0.11, tower-http 0.6; Postgres 18, Azurite 3.37.0, SeaweedFS 4.48; Docker, GitHub Actions.

**Spec:** [`docs/thiet-ke-web.md`](../thiet-ke-web.md) (mục 1, 2, 4, 5, 7) và mục 2 của [`docs/thiet-ke.md`](../thiet-ke.md).

## Global Constraints

- Tiền tố lệnh `/v1`; ba lệnh vận hành `/healthz`, `/livez`, `/openapi.json` không có tiền tố.
- Tên trường JSON đúng như thiết kế web: `id`, `tieu_de`, `mo_ta`, `anh_sha256` (chuỗi hex 64 ký tự), `anh_kieu`, `anh_byte`, `rong`, `cao`, `tao_luc` (RFC 3339); danh sách `{ bai, tiep }`; lỗi `{ loi, thong_bao }`.
- Mã lỗi và trạng thái HTTP: `ma_sai` 401, `khong_tim_thay` 404, `anh_qua_lon` 413, `khong_phai_anh` 415, `du_lieu_sai` 422, `thu_qua_nhieu` 429 (kèm `Retry-After`), `tam_ngung` 503, `chi_doc` 503.
- Ảnh gốc tối đa 1 048 576 byte; chỉ JPEG, PNG, WebP nhận dạng bằng byte đầu tệp; tối đa 50 000 000 điểm ảnh. Tiêu đề 1–100 ký tự, mô tả 0–1000 ký tự, sau chuẩn hóa NFC và bỏ khoảng trắng hai đầu.
- Danh sách mặc định 24 bài, tối đa 60. Ảnh nhỏ cạnh dài nhất 800 px, AVIF; ảnh gốc không quá 800 px mỗi cạnh thì dùng luôn ảnh gốc.
- Ảnh nhỏ chỉ tạo khi có người xem: mỗi `id` một lần, cả API một ảnh một lúc, ngoài luồng phục vụ; bộ nhớ đệm tối đa 64 MiB.
- Sai mã quá 10 lần trong 10 phút từ một IP thì trả 429. `X-Forwarded-For` chỉ được tin khi yêu cầu đến từ dải trong `PROXY_TIN_CAY`.
- `/healthz` chỉ trả 200 khi cấu trúc bảng đã tạo xong, `SELECT 1` chạy được và kho ảnh trả lời "không có" cho một khóa cố định, tất cả trong 2 giây.
- Không viết chú thích hay docstring trong code (quy tắc của kho).
- Không bí mật nào trong Git. Khóa của Azurite là khóa công khai của trình giả lập, được phép.

```rust
use anyhow::{Context, bail};
use ipnet::IpNet;

pub const PHIEN_BAN: &str = match option_env!("PHIEN_BAN") {
    Some(v) => v,
    None => "dev",
};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LoaiKho {
    Azure,
    S3,
}

#[derive(Clone, Debug)]
pub struct CauHinh {
    pub database_url: String,
    pub loai_kho: LoaiKho,
    pub ten_container: String,
    pub chi_doc: bool,
    pub ma_bi_mat: String,
    pub cum: String,
    pub vung: String,
    pub cors_nguon: Vec<String>,
    pub proxy_tin_cay: Vec<IpNet>,
    pub cong: u16,
}

impl CauHinh {
    pub fn tu_moi_truong() -> anyhow::Result<Self> {
        Self::tu_ham(|k| std::env::var(k).ok())
    }

    pub fn tu_ham(doc: impl Fn(&str) -> Option<String>) -> anyhow::Result<Self> {
        let bat_buoc = |k: &str| {
            doc(k)
                .filter(|v| !v.trim().is_empty())
                .with_context(|| format!("thiếu biến môi trường {k}"))
        };
        let danh_sach = |k: &str, mac_dinh: &str| -> Vec<String> {
            doc(k)
                .unwrap_or_else(|| mac_dinh.to_string())
                .split(',')
                .map(str::trim)
                .filter(|s| !s.is_empty())
                .map(String::from)
                .collect()
        };
        let loai_kho = match bat_buoc("KHO_ANH")?.as_str() {
            "azure" => LoaiKho::Azure,
            "s3" => LoaiKho::S3,
            khac => bail!("KHO_ANH phải là azure hoặc s3, nhận được {khac}"),
        };
        let cum = bat_buoc("CUM")?;
        if cum != "chinh" && cum != "du-phong" {
            bail!("CUM phải là chinh hoặc du-phong, nhận được {cum}");
        }
        let ma_bi_mat = bat_buoc("MA_BI_MAT")?;
        if ma_bi_mat.chars().count() < 16 {
            bail!("MA_BI_MAT phải dài ít nhất 16 ký tự");
        }
        let chi_doc = match doc("KHO_ANH_CHI_DOC").as_deref() {
            None | Some("") | Some("false") => false,
            Some("true") => true,
            Some(khac) => bail!("KHO_ANH_CHI_DOC phải là true hoặc false, nhận được {khac}"),
        };
        let proxy_tin_cay = danh_sach("PROXY_TIN_CAY", "")
            .iter()
            .map(|s| s.parse::<IpNet>().with_context(|| format!("PROXY_TIN_CAY sai: {s}")))
            .collect::<anyhow::Result<Vec<_>>>()?;
        let cong = doc("CONG")
            .map(|s| s.parse::<u16>())
            .transpose()
            .context("CONG phải là số cổng")?
            .unwrap_or(8080);
        Ok(Self {
            database_url: bat_buoc("DATABASE_URL")?,
            loai_kho,
            ten_container: doc("KHO_ANH_CONTAINER").unwrap_or_else(|| "anh".into()),
            chi_doc,
            ma_bi_mat,
            cum,
            vung: doc("VUNG").unwrap_or_default(),
            cors_nguon: danh_sach("CORS_NGUON", "https://dr.qivarn.id.vn"),
            proxy_tin_cay,
            cong,
        })
    }
}
```

```rust
use axum::Json;
use axum::http::{HeaderValue, StatusCode, header};
use axum::response::{IntoResponse, Response};
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum ApiLoi {
    #[error("Mã bí mật không đúng.")]
    MaSai,
    #[error("Không tìm thấy.")]
    KhongTimThay,
    #[error("{0}")]
    AnhQuaLon(&'static str),
    #[error("Tệp không phải ảnh JPG, PNG hoặc WebP đọc được.")]
    KhongPhaiAnh,
    #[error("{0}")]
    DuLieuSai(String),
    #[error("Thử sai quá nhiều lần. Thử lại sau {0} giây.")]
    ThuQuaNhieu(u64),
    #[error("Hệ thống tạm ngừng, thử lại sau.")]
    TamNgung,
    #[error("Hệ thống đang ở chế độ chỉ đọc.")]
    ChiDoc,
}

#[derive(Debug, Serialize, Deserialize, ToSchema)]
pub struct ThanLoi {
    pub loi: String,
    pub thong_bao: String,
}

impl ApiLoi {
    pub fn ma(&self) -> &'static str {
        match self {
            ApiLoi::MaSai => "ma_sai",
            ApiLoi::KhongTimThay => "khong_tim_thay",
            ApiLoi::AnhQuaLon(_) => "anh_qua_lon",
            ApiLoi::KhongPhaiAnh => "khong_phai_anh",
            ApiLoi::DuLieuSai(_) => "du_lieu_sai",
            ApiLoi::ThuQuaNhieu(_) => "thu_qua_nhieu",
            ApiLoi::TamNgung => "tam_ngung",
            ApiLoi::ChiDoc => "chi_doc",
        }
    }

    pub fn trang_thai(&self) -> StatusCode {
        match self {
            ApiLoi::MaSai => StatusCode::UNAUTHORIZED,
            ApiLoi::KhongTimThay => StatusCode::NOT_FOUND,
            ApiLoi::AnhQuaLon(_) => StatusCode::PAYLOAD_TOO_LARGE,
            ApiLoi::KhongPhaiAnh => StatusCode::UNSUPPORTED_MEDIA_TYPE,
            ApiLoi::DuLieuSai(_) => StatusCode::UNPROCESSABLE_ENTITY,
            ApiLoi::ThuQuaNhieu(_) => StatusCode::TOO_MANY_REQUESTS,
            ApiLoi::TamNgung | ApiLoi::ChiDoc => StatusCode::SERVICE_UNAVAILABLE,
        }
    }
}

impl IntoResponse for ApiLoi {
    fn into_response(self) -> Response {
        let than = ThanLoi { loi: self.ma().to_string(), thong_bao: self.to_string() };
        let mut r = (self.trang_thai(), Json(than)).into_response();
        if let ApiLoi::ThuQuaNhieu(giay) = self {
            r.headers_mut().insert(header::RETRY_AFTER, HeaderValue::from(giay));
        }
        r
    }
}

impl From<sqlx::Error> for ApiLoi {
    fn from(e: sqlx::Error) -> Self {
        tracing::error!(loi = %e, "loi co so du lieu");
        ApiLoi::TamNgung
    }
}

impl From<object_store::Error> for ApiLoi {
    fn from(e: object_store::Error) -> Self {
        tracing::error!(loi = %e, "loi kho anh");
        ApiLoi::TamNgung
    }
}
```

```rust
use std::io::Cursor;

use bytes::Bytes;
use image::{ImageFormat, ImageReader, Limits};
use sha2::{Digest, Sha256};

use crate::loi::ApiLoi;

pub const BYTE_TOI_DA: usize = 1_048_576;
pub const DIEM_ANH_TOI_DA: u64 = 50_000_000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum KieuAnh {
    Jpeg,
    Png,
    Webp,
}

impl KieuAnh {
    pub fn mime(self) -> &'static str {
        match self {
            KieuAnh::Jpeg => "image/jpeg",
            KieuAnh::Png => "image/png",
            KieuAnh::Webp => "image/webp",
        }
    }

    pub fn tu_mime(s: &str) -> Option<Self> {
        match s {
            "image/jpeg" => Some(KieuAnh::Jpeg),
            "image/png" => Some(KieuAnh::Png),
            "image/webp" => Some(KieuAnh::Webp),
            _ => None,
        }
    }

    pub fn nhan_dang(d: &[u8]) -> Option<Self> {
        if d.starts_with(&[0xFF, 0xD8, 0xFF]) {
            Some(KieuAnh::Jpeg)
        } else if d.starts_with(b"\x89PNG\r\n\x1a\n") {
            Some(KieuAnh::Png)
        } else if d.len() >= 12 && &d[0..4] == b"RIFF" && &d[8..12] == b"WEBP" {
            Some(KieuAnh::Webp)
        } else {
            None
        }
    }

    fn dinh_dang(self) -> ImageFormat {
        match self {
            KieuAnh::Jpeg => ImageFormat::Jpeg,
            KieuAnh::Png => ImageFormat::Png,
            KieuAnh::Webp => ImageFormat::WebP,
        }
    }
}

#[derive(Debug, Clone)]
pub struct AnhHopLe {
    pub kieu: KieuAnh,
    pub rong: u32,
    pub cao: u32,
    pub sha256: [u8; 32],
    pub du_lieu: Bytes,
}

pub fn kiem_tra(du_lieu: Bytes) -> Result<AnhHopLe, ApiLoi> {
    if du_lieu.len() > BYTE_TOI_DA {
        return Err(ApiLoi::AnhQuaLon("Ảnh lớn hơn 1 MB."));
    }
    let kieu = KieuAnh::nhan_dang(&du_lieu).ok_or(ApiLoi::KhongPhaiAnh)?;
    let (rong, cao) = ImageReader::with_format(Cursor::new(&du_lieu[..]), kieu.dinh_dang())
        .into_dimensions()
        .map_err(|_| ApiLoi::KhongPhaiAnh)?;
    if rong == 0 || cao == 0 {
        return Err(ApiLoi::KhongPhaiAnh);
    }
    if u64::from(rong) * u64::from(cao) > DIEM_ANH_TOI_DA {
        return Err(ApiLoi::AnhQuaLon("Ảnh có quá nhiều điểm ảnh."));
    }
    giai_ma(&du_lieu, kieu).map_err(|_| ApiLoi::KhongPhaiAnh)?;
    let sha256: [u8; 32] = Sha256::digest(&du_lieu).into();
    Ok(AnhHopLe { kieu, rong, cao, sha256, du_lieu })
}

pub fn giai_ma(du_lieu: &[u8], kieu: KieuAnh) -> image::ImageResult<image::DynamicImage> {
    let mut doc = ImageReader::with_format(Cursor::new(du_lieu), kieu.dinh_dang());
    let mut gioi_han = Limits::default();
    gioi_han.max_alloc = Some(256 * 1024 * 1024);
    doc.limits(gioi_han);
    doc.decode()
}
```

```rust
use std::collections::{HashMap, VecDeque};
use std::net::{IpAddr, SocketAddr};
use std::sync::Mutex;
use std::time::{Duration, Instant};

use axum::http::{HeaderMap, header};
use ipnet::IpNet;
use subtle::ConstantTimeEq;

use crate::loi::ApiLoi;

pub struct KiemTraMa {
    ma: Vec<u8>,
    sai: Mutex<HashMap<IpAddr, VecDeque<Instant>>>,
    toi_da: usize,
    cua_so: Duration,
}

impl KiemTraMa {
    pub fn moi(ma: &str) -> Self {
        Self::voi_gioi_han(ma, 10, Duration::from_secs(600))
    }

    pub fn voi_gioi_han(ma: &str, toi_da: usize, cua_so: Duration) -> Self {
        Self { ma: ma.as_bytes().to_vec(), sai: Mutex::new(HashMap::new()), toi_da, cua_so }
    }

    pub fn kiem_tra(&self, ip: IpAddr, ma_gui: Option<&str>, bay_gio: Instant) -> Result<(), ApiLoi> {
        let mut sai = self.sai.lock().expect("khoa bo dem sai ma");
        if sai.len() > 10_000 {
            sai.retain(|_, hang| {
                bo_cu(hang, bay_gio, self.cua_so);
                !hang.is_empty()
            });
        }
        let hang = sai.entry(ip).or_default();
        bo_cu(hang, bay_gio, self.cua_so);
        if hang.len() >= self.toi_da {
            let con_lai = self.cua_so.saturating_sub(bay_gio.duration_since(hang[0]));
            return Err(ApiLoi::ThuQuaNhieu(con_lai.as_secs().max(1)));
        }
        let dung: bool = ma_gui.map(|m| bool::from(m.as_bytes().ct_eq(&self.ma))).unwrap_or(false);
        if dung {
            let khong_con = hang.is_empty();
            if khong_con {
                sai.remove(&ip);
            }
            Ok(())
        } else {
            hang.push_back(bay_gio);
            Err(ApiLoi::MaSai)
        }
    }
}

fn bo_cu(hang: &mut VecDeque<Instant>, bay_gio: Instant, cua_so: Duration) {
    while hang.front().is_some_and(|t| bay_gio.duration_since(*t) >= cua_so) {
        hang.pop_front();
    }
}

pub fn ip_khach(nguon: SocketAddr, headers: &HeaderMap, tin_cay: &[IpNet]) -> IpAddr {
    let ip = nguon.ip();
    if tin_cay.iter().any(|n| n.contains(&ip)) {
        let tu_proxy = headers
            .get("x-forwarded-for")
            .and_then(|v| v.to_str().ok())
            .and_then(|s| s.split(',').next_back())
            .and_then(|s| s.trim().parse::<IpAddr>().ok());
        if let Some(x) = tu_proxy {
            return x;
        }
    }
    ip
}

pub fn ma_tu_header(headers: &HeaderMap) -> Option<&str> {
    headers.get(header::AUTHORIZATION)?.to_str().ok()?.strip_prefix("Bearer ")
}
```

```rust
use bytes::Bytes;
use object_store::aws::AmazonS3Builder;

use object_store::{BackoffConfig, ClientOptions, ObjectStore, PutPayload, RetryConfig};

use crate::cau_hinh::{CauHinh, LoaiKho};

#[derive(Clone)]
pub struct KhoAnh {
    kho: Arc<dyn ObjectStore>,
}

pub fn tuy_chon_mang() -> (ClientOptions, RetryConfig) {
    let tuy_chon = ClientOptions::new()
        .with_connect_timeout(Duration::from_secs(3))
        .with_timeout(Duration::from_secs(10));
    let thu_lai = RetryConfig {
        backoff: BackoffConfig::default(),
        max_retries: 2,
        retry_timeout: Duration::from_secs(15),
    };
    (tuy_chon, thu_lai)
}

impl KhoAnh {
    pub fn moi(kho: Arc<dyn ObjectStore>) -> Self {
        Self { kho }
    }

    pub fn tu_cau_hinh(c: &CauHinh) -> anyhow::Result<Self> {
        let (tuy_chon, thu_lai) = tuy_chon_mang();
        let kho: Arc<dyn ObjectStore> = match c.loai_kho {
            LoaiKho::Azure => Arc::new(
                MicrosoftAzureBuilder::from_env()
                    .with_container_name(&c.ten_container)
                    .with_client_options(tuy_chon)
                    .with_retry(thu_lai)
                    .build()?,
            ),
            LoaiKho::S3 => Arc::new(
                AmazonS3Builder::from_env()
                    .with_bucket_name(&c.ten_container)
                    .with_client_options(tuy_chon)
                    .with_retry(thu_lai)
                    .build()?,
            ),
        };
        Ok(Self::moi(kho))
    }

    fn duong_goc(id: Uuid) -> Path {
        Path::from(format!("goc/{id}"))
    }

    fn duong_nho(id: Uuid) -> Path {
        Path::from(format!("nho/{id}.avif"))
    }

    pub async fn cat_goc(&self, id: Uuid, du_lieu: Bytes) -> object_store::Result<()> {
        self.kho.put(&Self::duong_goc(id), PutPayload::from(du_lieu)).await.map(|_| ())
    }

    pub async fn lay_goc(&self, id: Uuid) -> object_store::Result<Option<Bytes>> {
        self.lay(&Self::duong_goc(id)).await
    }

    pub async fn cat_nho(&self, id: Uuid, du_lieu: Bytes) -> object_store::Result<()> {
        self.kho.put(&Self::duong_nho(id), PutPayload::from(du_lieu)).await.map(|_| ())
    }

    pub async fn lay_nho(&self, id: Uuid) -> object_store::Result<Option<Bytes>> {
        self.lay(&Self::duong_nho(id)).await
    }

    pub async fn xoa_nho(&self, id: Uuid) -> object_store::Result<()> {
        match self.kho.delete(&Self::duong_nho(id)).await {
            Ok(()) | Err(object_store::Error::NotFound { .. }) => Ok(()),
            Err(e) => Err(e),
        }
    }

    pub async fn tham_do(&self) -> object_store::Result<()> {
        match self.kho.head(&Path::from("suc-khoe/khong-ton-tai")).await {
            Ok(_) | Err(object_store::Error::NotFound { .. }) => Ok(()),
            Err(e) => Err(e),
        }
    }

    async fn lay(&self, duong: &Path) -> object_store::Result<Option<Bytes>> {
        match self.kho.get(duong).await {
            Ok(r) => Ok(Some(r.bytes().await?)),
            Err(object_store::Error::NotFound { .. }) => Ok(None),
            Err(e) => Err(e),
        }
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Mutex};

use bytes::Bytes;
use fast_image_resize::images::Image;
use fast_image_resize::{FilterType, PixelType, ResizeAlg, ResizeOptions, Resizer};
use lru::LruCache;
use tokio::sync::{OnceCell, Semaphore};
use uuid::Uuid;

use crate::anh::{KieuAnh, giai_ma};
use crate::kho_anh::KhoAnh;
use crate::loi::ApiLoi;

pub const CANH_TOI_DA: u32 = 800;
const BO_NHO_DEM_TOI_DA: usize = 64 * 1024 * 1024;

pub fn can_anh_nho(rong: u32, cao: u32) -> bool {
    rong > CANH_TOI_DA || cao > CANH_TOI_DA
}

pub fn kich_thuoc_nho(rong: u32, cao: u32) -> (u32, u32) {
    let thu_nho = |canh: u32, canh_dai: u32| -> u32 {
        ((u64::from(canh) * u64::from(CANH_TOI_DA) + u64::from(canh_dai) / 2) / u64::from(canh_dai)).max(1) as u32
    };
    if rong >= cao {
        (CANH_TOI_DA, thu_nho(cao, rong))
    } else {
        (thu_nho(rong, cao), CANH_TOI_DA)
    }
}

pub fn tao_anh_nho(goc: &[u8], kieu: KieuAnh) -> anyhow::Result<Vec<u8>> {
    let anh = giai_ma(goc, kieu)?.to_rgba8();
    let (rong, cao) = anh.dimensions();
    let (rong_nho, cao_nho) = kich_thuoc_nho(rong, cao);
    let nguon = Image::from_vec_u8(rong, cao, anh.into_raw(), PixelType::U8x4)?;
    let mut dich = Image::new(rong_nho, cao_nho, PixelType::U8x4);
    Resizer::new().resize(
        &nguon,
        &mut dich,
        &ResizeOptions::new().resize_alg(ResizeAlg::Convolution(FilterType::Lanczos3)),
    )?;
    let diem: Vec<ravif::RGBA8> = dich
        .buffer()
        .chunks_exact(4)
        .map(|p| ravif::RGBA8::new(p[0], p[1], p[2], p[3]))
        .collect();
    let ket_qua = ravif::Encoder::new()
        .with_quality(60.0)
        .with_alpha_quality(60.0)
        .with_speed(6)
        .encode_rgba(ravif::Img::new(diem.as_slice(), rong_nho as usize, cao_nho as usize))?;
    Ok(ket_qua.avif_file)
}

pub struct BoNhoDem {
    ds: LruCache<Uuid, Bytes>,
    tong: usize,
    gioi_han: usize,
}

impl BoNhoDem {
    pub fn moi(gioi_han: usize) -> Self {
        Self { ds: LruCache::unbounded(), tong: 0, gioi_han }
    }

    pub fn lay(&mut self, id: &Uuid) -> Option<Bytes> {
        self.ds.get(id).cloned()
    }

    pub fn dat(&mut self, id: Uuid, du_lieu: Bytes) {
        if du_lieu.len() > self.gioi_han {
            return;
        }
        if let Some(cu) = self.ds.put(id, du_lieu.clone()) {
            self.tong -= cu.len();
        }
        self.tong += du_lieu.len();
        while self.tong > self.gioi_han {
            match self.ds.pop_lru() {
                Some((_, bo)) => self.tong -= bo.len(),
                None => break,
            }
        }
    }

    pub fn tong(&self) -> usize {
        self.tong
    }
}

pub struct AnhTraVe {
    pub du_lieu: Bytes,
    pub kieu: &'static str,
}

pub struct DichVuAnhNho {
    kho: KhoAnh,
    chi_doc: bool,
    dem: Mutex<BoNhoDem>,
    dang_tao: Mutex<HashMap<Uuid, Arc<OnceCell<Bytes>>>>,
    mot_luc: Semaphore,
    so_lan_tao: AtomicU64,
}

impl DichVuAnhNho {
    pub fn moi(kho: KhoAnh, chi_doc: bool) -> Self {
        Self {
            kho,
            chi_doc,
            dem: Mutex::new(BoNhoDem::moi(BO_NHO_DEM_TOI_DA)),
            dang_tao: Mutex::new(HashMap::new()),
            mot_luc: Semaphore::new(1),
            so_lan_tao: AtomicU64::new(0),
        }
    }

    pub fn so_lan_tao(&self) -> u64 {
        self.so_lan_tao.load(Ordering::Relaxed)
    }

    pub async fn lay(&self, id: Uuid, kieu_goc: KieuAnh, rong: u32, cao: u32) -> Result<AnhTraVe, ApiLoi> {
        if !can_anh_nho(rong, cao) {
            let goc = self.kho.lay_goc(id).await?.ok_or(ApiLoi::KhongTimThay)?;
            return Ok(AnhTraVe { du_lieu: goc, kieu: kieu_goc.mime() });
        }
        let tu_dem = self.dem.lock().expect("khoa bo nho dem").lay(&id);
        if let Some(b) = tu_dem {
            return Ok(avif(b));
        }
        if let Some(b) = self.kho.lay_nho(id).await? {
            self.dem.lock().expect("khoa bo nho dem").dat(id, b.clone());
            return Ok(avif(b));
        }
        let o = self
            .dang_tao
            .lock()
            .expect("khoa dang tao")
            .entry(id)
            .or_insert_with(|| Arc::new(OnceCell::new()))
            .clone();
        let ket_qua = o.get_or_try_init(|| self.tao(id, kieu_goc)).await.cloned();
        {
            let mut dang_tao = self.dang_tao.lock().expect("khoa dang tao");
            if dang_tao.get(&id).is_some_and(|x| Arc::ptr_eq(x, &o)) {
                dang_tao.remove(&id);
            }
        }
        Ok(avif(ket_qua?))
    }

    async fn tao(&self, id: Uuid, kieu_goc: KieuAnh) -> Result<Bytes, ApiLoi> {
        let _luot = self.mot_luc.acquire().await.map_err(|_| ApiLoi::TamNgung)?;
        let tu_dem = self.dem.lock().expect("khoa bo nho dem").lay(&id);
        if let Some(b) = tu_dem {
            return Ok(b);
        }
        let goc = self.kho.lay_goc(id).await?.ok_or(ApiLoi::KhongTimThay)?;
        let du_lieu = tokio::task::spawn_blocking(move || tao_anh_nho(&goc, kieu_goc))
            .await
            .map_err(|_| ApiLoi::TamNgung)?
            .map_err(|e| {
                tracing::error!(%id, loi = %e, "khong tao duoc anh nho");
                ApiLoi::TamNgung
            })?;
        let du_lieu = Bytes::from(du_lieu);
        self.so_lan_tao.fetch_add(1, Ordering::Relaxed);
        self.dem.lock().expect("khoa bo nho dem").dat(id, du_lieu.clone());
        if !self.chi_doc {
            if let Err(e) = self.kho.cat_nho(id, du_lieu.clone()).await {
```

```rust
use serde::{Deserialize, Serialize};
use sqlx::PgPool;
use time::OffsetDateTime;
use utoipa::ToSchema;
use uuid::Uuid;

use crate::anh::AnhHopLe;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, ToSchema)]
pub struct Bai {
    pub id: Uuid,
    pub tieu_de: String,
    pub mo_ta: String,
    pub anh_sha256: String,
    pub anh_kieu: String,
    pub anh_byte: i32,
    pub rong: i32,
    pub cao: i32,
    #[serde(with = "time::serde::rfc3339")]
    #[schema(value_type = String, format = DateTime)]
    pub tao_luc: OffsetDateTime,
}

struct DongBai {
    id: Uuid,
    tieu_de: String,
    mo_ta: String,
    anh_sha256: Vec<u8>,
    anh_kieu: String,
    anh_byte: i32,
    rong: i32,
    cao: i32,
    tao_luc: OffsetDateTime,
}

impl From<DongBai> for Bai {
    fn from(d: DongBai) -> Self {
        Self {
            id: d.id,
            tieu_de: d.tieu_de,
            mo_ta: d.mo_ta,
            anh_sha256: hex::encode(d.anh_sha256),
            anh_kieu: d.anh_kieu,
            anh_byte: d.anh_byte,
            rong: d.rong,
            cao: d.cao,
            tao_luc: d.tao_luc,
        }
    }
}

pub struct BaiMoi<'a> {
    pub id: Uuid,
    pub ma_lan_dang: Uuid,
    pub tieu_de: &'a str,
    pub mo_ta: &'a str,
    pub anh: &'a AnhHopLe,
}

pub enum KetQuaThem {
    Moi(Bai),
    DaCo(Bai),
}

pub async fn them(pool: &PgPool, b: &BaiMoi<'_>) -> sqlx::Result<KetQuaThem> {
    let dong = sqlx::query_as!(
        DongBai,
        r#"INSERT INTO bai (id, ma_lan_dang, tieu_de, mo_ta, anh_sha256, anh_kieu, anh_byte, rong, cao)
           VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9)
           ON CONFLICT (ma_lan_dang) DO NOTHING
           RETURNING id AS "id!", tieu_de AS "tieu_de!", mo_ta AS "mo_ta!", anh_sha256 AS "anh_sha256!",
                     anh_kieu AS "anh_kieu!", anh_byte AS "anh_byte!", rong AS "rong!", cao AS "cao!", tao_luc AS "tao_luc!""#,
        b.id,
        b.ma_lan_dang,
        b.tieu_de,
        b.mo_ta,
        &b.anh.sha256[..],
        b.anh.kieu.mime(),
        b.anh.du_lieu.len() as i32,
        b.anh.rong as i32,
        b.anh.cao as i32,
    )
    .fetch_optional(pool)
    .await?;
    match dong {
        Some(d) => Ok(KetQuaThem::Moi(d.into())),
        None => {
            let cu = tim_theo_ma_lan_dang(pool, b.ma_lan_dang).await?.ok_or(sqlx::Error::RowNotFound)?;
            Ok(KetQuaThem::DaCo(cu))
        }
    }
}

pub async fn lay(pool: &PgPool, id: Uuid) -> sqlx::Result<Option<Bai>> {
    let d = sqlx::query_as!(
        DongBai,
        "SELECT id, tieu_de, mo_ta, anh_sha256, anh_kieu, anh_byte, rong, cao, tao_luc FROM bai WHERE id = $1",
        id
    )
    .fetch_optional(pool)
    .await?;
    Ok(d.map(Bai::from))
}

pub async fn tim_theo_ma_lan_dang(pool: &PgPool, ma: Uuid) -> sqlx::Result<Option<Bai>> {
    let d = sqlx::query_as!(
        DongBai,
        "SELECT id, tieu_de, mo_ta, anh_sha256, anh_kieu, anh_byte, rong, cao, tao_luc FROM bai WHERE ma_lan_dang = $1",
        ma
    )
    .fetch_optional(pool)
    .await?;
    Ok(d.map(Bai::from))
}

pub async fn trang(pool: &PgPool, truoc: Option<Uuid>, so: i64) -> sqlx::Result<Vec<Bai>> {
    let ds = sqlx::query_as!(
        DongBai,
        "SELECT id, tieu_de, mo_ta, anh_sha256, anh_kieu, anh_byte, rong, cao, tao_luc FROM bai
         WHERE ($1::uuid IS NULL OR id < $1) ORDER BY id DESC LIMIT $2",
        truoc,
        so
    )
    .fetch_all(pool)
    .await?;
    Ok(ds.into_iter().map(Bai::from).collect())
}
```

```rust
#[utoipa::path(
    get,
    path = "/v1/bai",
    params(ThamSoTrang),
    responses(
        (status = 200, body = TrangBai),
        (status = 422, body = ThanLoi),
        (status = 503, body = ThanLoi)
    )

pub async fn danh_sach(
    State(tt): State<Arc<TrangThai>>,
    q: Result<Query<ThamSoTrang>, QueryRejection>,
) -> Result<Json<TrangBai>, ApiLoi> {
    let Query(q) = q.map_err(|_| ApiLoi::DuLieuSai("Tham số không hợp lệ.".into()))?;
    let so = q.so.unwrap_or(24);
    if !(1..=60).contains(&so) {
        return Err(ApiLoi::DuLieuSai("Số bài mỗi trang phải từ 1 đến 60.".into()));
    }
    let mut ds = csdl::trang(&tt.pool, q.truoc, so + 1).await?;
    let tiep = if ds.len() as i64 > so {
        ds.truncate(so as usize);
        ds.last().map(|b| b.id)
    } else {
        None
    };
    Ok(Json(TrangBai { bai: ds, tiep }))
}

    get,
    path = "/v1/bai/{id}",
    params(("id" = Uuid, Path)),
    responses((status = 200, body = Bai), (status = 404, body = ThanLoi), (status = 503, body = ThanLoi))
)]

    get,
    path = "/v1/bai/{id}/anh",
    params(("id" = Uuid, Path)),
    responses((status = 200, description = "Ảnh gốc, kiểu theo anh_kieu"), (status = 404, body = ThanLoi))
)]
pub async fn anh_goc(
    State(tt): State<Arc<TrangThai>>,
    id: Result<Path<Uuid>, PathRejection>,
) -> Result<Response, ApiLoi> {
    let bai = tim(&tt, id).await?;
    let du_lieu = tt.kho.lay_goc(bai.id).await?.ok_or(ApiLoi::KhongTimThay)?;
    Ok(tra_anh(du_lieu, kieu_cua(&bai)?.mime(), bai.anh_sha256))

    get,
    path = "/v1/bai/{id}/anh-nho",
    params(("id" = Uuid, Path)),
    responses((status = 200, description = "Ảnh nhỏ AVIF, hoặc ảnh gốc nếu ảnh đã nhỏ"), (status = 404, body = ThanLoi))
)]
pub async fn anh_nho(
    State(tt): State<Arc<TrangThai>>,
    id: Result<Path<Uuid>, PathRejection>,
) -> Result<Response, ApiLoi> {
    let bai = tim(&tt, id).await?;
    let kieu = kieu_cua(&bai)?;
    let ra = tt.anh_nho.lay(bai.id, kieu, bai.rong as u32, bai.cao as u32).await?;
    Ok(tra_anh(ra.du_lieu, ra.kieu, format!("{}-nho", bai.anh_sha256)))
}

    let Path(id) = id.map_err(|_| ApiLoi::KhongTimThay)?;
    csdl::lay(&tt.pool, id).await?.ok_or(ApiLoi::KhongTimThay)
}

    KieuAnh::tu_mime(&bai.anh_kieu).ok_or(ApiLoi::TamNgung)
}

    (
        [
            (header::CONTENT_TYPE, kieu.to_string()),
            (header::ETAG, format!("\"{etag}\"")),
            (header::CACHE_CONTROL, "public, max-age=31536000, immutable".to_string()),
        ],
        du_lieu,
    )
        .into_response()
}
```

```rust
    let han = Duration::from_secs(2);

        vung: tt.cau_hinh.vung.clone(),

        hong,
```

```rust
pub const GIOI_HAN_THAN: usize = 1_258_291;

pub fn cac_tuyen() -> OpenApiRouter<Arc<TrangThai>> {
    OpenApiRouter::with_openapi(TaiLieu::openapi())
        .routes(routes!(bai::danh_sach))
        .routes(routes!(bai::mot_bai))
        .routes(routes!(bai::anh_goc))
        .routes(routes!(bai::anh_nho))
        .routes(routes!(suc_khoe::healthz))
        .routes(routes!(suc_khoe::livez))
}

pub fn ung_dung(tt: Arc<TrangThai>) -> Router {
    let (router, api) = cac_tuyen().split_for_parts();
    let nguon: Vec<HeaderValue> = tt.cau_hinh.cors_nguon.iter().filter_map(|s| HeaderValue::from_str(s).ok()).collect();
    let cors = CorsLayer::new()
        .allow_origin(AllowOrigin::list(nguon))
        .allow_methods([Method::GET, Method::POST])
        .allow_headers([header::AUTHORIZATION, header::CONTENT_TYPE])
        .max_age(Duration::from_secs(600));
    router
        .route("/openapi.json", get(move || {
            let api = api.clone();
            async move { Json(api) }
        }))
        .with_state(tt)
        .layer(DefaultBodyLimit::max(GIOI_HAN_THAN))
        .layer(SetResponseHeaderLayer::overriding(
            HeaderName::from_static("x-content-type-options"),
            HeaderValue::from_static("nosniff"),
        ))
        .layer(cors)
        .layer(
            TraceLayer::new_for_http()
                .make_span_with(DefaultMakeSpan::new().level(Level::INFO))
                .on_response(DefaultOnResponse::new().level(Level::INFO)),
        )
}
```

```rust
use std::net::SocketAddr;
use std::time::Instant;

use axum::extract::ConnectInfo;
use axum::extract::multipart::{Multipart, MultipartError, MultipartRejection};
use axum::http::{HeaderMap, StatusCode};

use crate::anh;
use crate::csdl::{BaiMoi, KetQuaThem};
use crate::{ma_bi_mat, van_ban};

#[derive(ToSchema)]
#[allow(dead_code)]
pub struct FormDangBai {
    ma_lan_dang: Uuid,
    tieu_de: String,
    mo_ta: String,
    #[schema(value_type = String, format = Binary)]
    anh: Vec<u8>,
}

struct Form {
    ma_lan_dang: Uuid,
    tieu_de: String,
    mo_ta: String,
    anh: Bytes,
}

#[utoipa::path(
    post,
    path = "/v1/bai",
    request_body(content = FormDangBai, content_type = "multipart/form-data"),
    security(("ma_bi_mat" = [])),
    responses(
        (status = 201, body = Bai),
        (status = 200, body = Bai),
        (status = 401, body = ThanLoi),
        (status = 413, body = ThanLoi),
        (status = 415, body = ThanLoi),
        (status = 422, body = ThanLoi),
        (status = 429, body = ThanLoi),
        (status = 503, body = ThanLoi)
    )
)]
pub async fn dang_bai(
    State(tt): State<Arc<TrangThai>>,
    ConnectInfo(nguon): ConnectInfo<SocketAddr>,
    headers: HeaderMap,
    multipart: Result<Multipart, MultipartRejection>,
) -> Result<(StatusCode, Json<Bai>), ApiLoi> {
    if tt.cau_hinh.chi_doc {
        return Err(ApiLoi::ChiDoc);
    }
    let ip = ma_bi_mat::ip_khach(nguon, &headers, &tt.cau_hinh.proxy_tin_cay);
    tt.ma.kiem_tra(ip, ma_bi_mat::ma_tu_header(&headers), Instant::now())?;
    let multipart = multipart.map_err(|_| ApiLoi::DuLieuSai("Cần gửi multipart/form-data.".into()))?;
    let form = doc_form(multipart).await?;
    if let Some(cu) = csdl::tim_theo_ma_lan_dang(&tt.pool, form.ma_lan_dang).await? {
        return Ok((StatusCode::OK, Json(cu)));
    }
    let tieu_de = van_ban::tieu_de(&form.tieu_de)?;
    let mo_ta = van_ban::mo_ta(&form.mo_ta)?;
    let anh_hop_le = tokio::task::spawn_blocking(move || anh::kiem_tra(form.anh))
        .await
        .map_err(|_| ApiLoi::TamNgung)??;
    let id = Uuid::now_v7();
    tt.kho.cat_goc(id, anh_hop_le.du_lieu.clone()).await?;
    let moi = BaiMoi { id, ma_lan_dang: form.ma_lan_dang, tieu_de: &tieu_de, mo_ta: &mo_ta, anh: &anh_hop_le };
    match csdl::them(&tt.pool, &moi).await? {
        KetQuaThem::Moi(b) => Ok((StatusCode::CREATED, Json(b))),
        KetQuaThem::DaCo(b) => Ok((StatusCode::OK, Json(b))),
    }
}

async fn doc_form(mut m: Multipart) -> Result<Form, ApiLoi> {
    let (mut ma, mut tieu_de, mut mo_ta, mut anh) = (None, None, None, None);
    while let Some(truong) = m.next_field().await.map_err(loi_multipart)? {
        match truong.name() {
            Some("ma_lan_dang") => ma = Some(truong.text().await.map_err(loi_multipart)?),
            Some("tieu_de") => tieu_de = Some(truong.text().await.map_err(loi_multipart)?),
            Some("mo_ta") => mo_ta = Some(truong.text().await.map_err(loi_multipart)?),
            Some("anh") => anh = Some(truong.bytes().await.map_err(loi_multipart)?),
            _ => {}
        }
    }
    let ma_lan_dang = ma
        .as_deref()
        .and_then(|s| Uuid::parse_str(s.trim()).ok())
        .ok_or_else(|| ApiLoi::DuLieuSai("Thiếu hoặc sai ma_lan_dang.".into()))?;
    Ok(Form {
        ma_lan_dang,
        tieu_de: tieu_de.ok_or_else(|| ApiLoi::DuLieuSai("Thiếu tiêu đề.".into()))?,
        mo_ta: mo_ta.unwrap_or_default(),
        anh: anh.ok_or_else(|| ApiLoi::DuLieuSai("Thiếu ảnh.".into()))?,
    })
}

fn loi_multipart(e: MultipartError) -> ApiLoi {
    if e.status() == StatusCode::PAYLOAD_TOO_LARGE {
        ApiLoi::AnhQuaLon("Ảnh lớn hơn 1 MB.")
    } else {
        ApiLoi::DuLieuSai("Dữ liệu gửi lên không đọc được.".into())
    }
}
```
