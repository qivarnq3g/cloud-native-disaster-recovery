# Kế hoạch làm API

> **Cho người thực hiện (agent):** dùng superpowers:subagent-driven-development (khuyên dùng) hoặc superpowers:executing-plans để làm theo từng task. Các bước dùng ô `- [ ]` để đánh dấu.

**Goal:** API JSON bằng Rust cho web đăng ảnh: danh sách, xem bài, ảnh gốc, ảnh nhỏ, đăng bài có mã bí mật, kiểm tra còn sống; chạy với Postgres và kho ảnh Azure Blob hoặc S3; đóng gói thành image nhỏ; kiểm tra tự động trên GitHub Actions.

**Architecture:** một crate `app/api` (thư viện cộng một tệp chạy). Mỗi tệp một việc: cấu hình, lỗi, văn bản, ảnh, mã bí mật, kho ảnh, ảnh nhỏ, cơ sở dữ liệu, trạng thái chung, định tuyến, OpenAPI. Kiểm thử đơn vị nằm trong từng tệp; kiểm thử chạy thật nằm trong `tests/`, chạy với Postgres, Azurite và SeaweedFS trong Docker Compose. `ci` chạy toàn bộ, so OpenAPI, đo image, đẩy image lên GitHub Container Registry khi vào `main`.

**Tech Stack:** Rust 1.97.1 (edition 2024), axum 0.8, tokio 1, sqlx 0.8 (Postgres, macro kiểm tra lúc biên dịch, chế độ offline), object_store 0.12 (Azure, S3), utoipa 5 + utoipa-axum 0.2, image 0.25, fast_image_resize 5, ravif 0.11, tower-http 0.6; Postgres 18, Azurite 3.37.0, SeaweedFS 4.48; Docker, GitHub Actions.

**Spec:** [`docs/thiet-ke-web.md`](../thiet-ke-web.md) (mục 1, 2, 4, 5, 7) và mục 2 của [`docs/thiet-ke.md`](../thiet-ke.md).

## Global Constraints

- Tiền tố lệnh `/v1`; ba lệnh vận hành `/healthz`, `/livez`, `/openapi.json` không có tiền tố.
- Tên trường JSON đúng như thiết kế web: `id`, `title`, `description`, `image_sha256` (chuỗi hex 64 ký tự), `image_type`, `image_bytes`, `width`, `height`, `created_at` (RFC 3339); danh sách `{ posts, next }`; lỗi `{ error, message }`.
- Mã lỗi và trạng thái HTTP: `invalid_code` 401, `not_found` 404, `image_too_large` 413, `not_an_image` 415, `invalid_input` 422, `too_many_attempts` 429 (kèm `Retry-After`), `unavailable` 503, `read_only` 503.
- Ảnh gốc tối đa 1 048 576 byte; chỉ JPEG, PNG, WebP nhận dạng bằng byte đầu tệp; tối đa 50 000 000 điểm ảnh. Tiêu đề 1–100 ký tự, mô tả 0–1000 ký tự, sau chuẩn hóa NFC và bỏ khoảng trắng hai đầu.
- Danh sách mặc định 24 bài, tối đa 60. Ảnh nhỏ cạnh dài nhất 800 px, AVIF; ảnh gốc không quá 800 px mỗi cạnh thì dùng luôn ảnh gốc.
- Ảnh nhỏ chỉ tạo khi có người xem: mỗi `id` một lần, cả API một ảnh một lúc, ngoài luồng phục vụ; bộ nhớ đệm tối đa 64 MiB.
- Sai mã quá 10 lần trong 10 phút từ một IP thì trả 429. `X-Forwarded-For` chỉ được tin khi yêu cầu đến từ dải trong `TRUSTED_PROXIES`.
- `/healthz` chỉ trả 200 khi cấu trúc bảng đã tạo xong, `SELECT 1` chạy được và kho ảnh trả lời "không có" cho một khóa cố định, tất cả trong 2 giây.
- Không viết chú thích hay docstring trong code (quy tắc của kho).
- Không bí mật nào trong Git. Khóa của Azurite là khóa công khai của trình giả lập, được phép.

```rust
use anyhow::{Context, bail};
use ipnet::IpNet;

pub const APP_VERSION: &str = match option_env!("APP_VERSION") {
    Some(v) => v,
    None => "dev",
};

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum StoreKind {
    Azure,
    S3,
}

#[derive(Clone, Debug)]
pub struct Config {
    pub database_url: String,
    pub store_kind: StoreKind,
    pub container: String,
    pub read_only: bool,
    pub secret_code: String,
    pub cluster: String,
    pub region: String,
    pub cors_origins: Vec<String>,
    pub trusted_proxies: Vec<IpNet>,
    pub port: u16,
}

impl Config {
    pub fn from_env() -> anyhow::Result<Self> {
        Self::from_lookup(|k| std::env::var(k).ok())
    }

    pub fn from_lookup(lookup: impl Fn(&str) -> Option<String>) -> anyhow::Result<Self> {
        let required = |k: &str| {
            lookup(k)
                .filter(|v| !v.trim().is_empty())
                .with_context(|| format!("thiếu biến môi trường {k}"))
        };
        let list = |k: &str, default: &str| -> Vec<String> {
            lookup(k)
                .unwrap_or_else(|| default.to_string())
                .split(',')
                .map(str::trim)
                .filter(|s| !s.is_empty())
                .map(String::from)
                .collect()
        };
        let store_kind = match required("IMAGE_STORE")?.as_str() {
            "azure" => StoreKind::Azure,
            "s3" => StoreKind::S3,
            other => bail!("IMAGE_STORE phải là azure hoặc s3, nhận được {other}"),
        };
        let cluster = required("CLUSTER")?;
        if cluster != "primary" && cluster != "standby" {
            bail!("CLUSTER phải là primary hoặc standby, nhận được {cluster}");
        }
        let secret_code = required("SECRET_CODE")?;
        if secret_code.chars().count() < 16 {
            bail!("SECRET_CODE phải dài ít nhất 16 ký tự");
        }
        let read_only = match lookup("IMAGE_STORE_READ_ONLY").as_deref() {
            None | Some("") | Some("false") => false,
            Some("true") => true,
            Some(other) => bail!("IMAGE_STORE_READ_ONLY phải là true hoặc false, nhận được {other}"),
        };
        let trusted_proxies = list("TRUSTED_PROXIES", "")
            .iter()
            .map(|s| s.parse::<IpNet>().with_context(|| format!("TRUSTED_PROXIES sai: {s}")))
            .collect::<anyhow::Result<Vec<_>>>()?;
        let port = lookup("PORT")
            .map(|s| s.parse::<u16>())
            .transpose()
            .context("PORT phải là số cổng")?
            .unwrap_or(8080);
        Ok(Self {
            database_url: required("DATABASE_URL")?,
            store_kind,
            container: lookup("IMAGE_STORE_CONTAINER").unwrap_or_else(|| "images".into()),
            read_only,
            secret_code,
            cluster,
            region: lookup("REGION").unwrap_or_default(),
            cors_origins: list("CORS_ORIGINS", "https://dr.qivarn.id.vn"),
            trusted_proxies,
            port,
        })
    }
}
```

```rust
use axum::Json;
use axum::http::{HeaderValue, StatusCode, header};
use axum::response::{IntoResponse, Response};
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum ApiError {
    #[error("Mã bí mật không đúng.")]
    InvalidCode,
    #[error("Không tìm thấy.")]
    NotFound,
    #[error("{0}")]
    ImageTooLarge(&'static str),
    #[error("Tệp không phải ảnh JPG, PNG hoặc WebP đọc được.")]
    NotAnImage,
    #[error("{0}")]
    InvalidInput(String),
    #[error("Thử sai quá nhiều lần. Thử lại sau {0} giây.")]
    TooManyAttempts(u64),
    #[error("Hệ thống tạm ngừng, thử lại sau.")]
    Unavailable,
    #[error("Hệ thống đang ở chế độ chỉ đọc.")]
    ReadOnly,
}

#[derive(Debug, Serialize, Deserialize, ToSchema)]
pub struct ErrorBody {
    pub error: String,
    pub message: String,
}

impl ApiError {
    pub fn code(&self) -> &'static str {
        match self {
            ApiError::InvalidCode => "invalid_code",
            ApiError::NotFound => "not_found",
            ApiError::ImageTooLarge(_) => "image_too_large",
            ApiError::NotAnImage => "not_an_image",
            ApiError::InvalidInput(_) => "invalid_input",
            ApiError::TooManyAttempts(_) => "too_many_attempts",
            ApiError::Unavailable => "unavailable",
            ApiError::ReadOnly => "read_only",
        }
    }

    pub fn status(&self) -> StatusCode {
        match self {
            ApiError::InvalidCode => StatusCode::UNAUTHORIZED,
            ApiError::NotFound => StatusCode::NOT_FOUND,
            ApiError::ImageTooLarge(_) => StatusCode::PAYLOAD_TOO_LARGE,
            ApiError::NotAnImage => StatusCode::UNSUPPORTED_MEDIA_TYPE,
            ApiError::InvalidInput(_) => StatusCode::UNPROCESSABLE_ENTITY,
            ApiError::TooManyAttempts(_) => StatusCode::TOO_MANY_REQUESTS,
            ApiError::Unavailable | ApiError::ReadOnly => StatusCode::SERVICE_UNAVAILABLE,
        }
    }
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let body = ErrorBody { error: self.code().to_string(), message: self.to_string() };
        let mut r = (self.status(), Json(body)).into_response();
        if let ApiError::TooManyAttempts(seconds) = self {
            r.headers_mut().insert(header::RETRY_AFTER, HeaderValue::from(seconds));
        }
        r
    }
}

impl From<sqlx::Error> for ApiError {
    fn from(e: sqlx::Error) -> Self {
        tracing::error!(error = %e, "database error");
        ApiError::Unavailable
    }
}

impl From<object_store::Error> for ApiError {
    fn from(e: object_store::Error) -> Self {
        tracing::error!(error = %e, "image store error");
        ApiError::Unavailable
    }
}
```

```rust
use unicode_normalization::UnicodeNormalization;

use crate::error::ApiError;

pub const MAX_TITLE_CHARS: usize = 100;
pub const MAX_DESCRIPTION_CHARS: usize = 1000;

pub fn title(input: &str) -> Result<String, ApiError> {
    let s = input.nfc().collect::<String>().trim().to_string();
    if s.chars().any(char::is_control) {
        return Err(ApiError::InvalidInput("Tiêu đề có ký tự không hợp lệ.".into()));
    }
    let n = s.chars().count();
    if n == 0 {
```

```rust
use std::io::Cursor;

use bytes::Bytes;
use image::{ImageFormat, ImageReader, Limits};
use sha2::{Digest, Sha256};

use crate::error::ApiError;

pub const MAX_BYTES: usize = 1_048_576;
pub const MAX_PIXELS: u64 = 50_000_000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ImageType {
    Jpeg,
    Png,
    Webp,
}

impl ImageType {
    pub fn mime(self) -> &'static str {
        match self {
            ImageType::Jpeg => "image/jpeg",
            ImageType::Png => "image/png",
            ImageType::Webp => "image/webp",
        }
    }

    pub fn from_mime(s: &str) -> Option<Self> {
        match s {
            "image/jpeg" => Some(ImageType::Jpeg),
            "image/png" => Some(ImageType::Png),
            "image/webp" => Some(ImageType::Webp),
            _ => None,
        }
    }

    pub fn detect(d: &[u8]) -> Option<Self> {
        if d.starts_with(&[0xFF, 0xD8, 0xFF]) {
            Some(ImageType::Jpeg)
        } else if d.starts_with(b"\x89PNG\r\n\x1a\n") {
            Some(ImageType::Png)
        } else if d.len() >= 12 && &d[0..4] == b"RIFF" && &d[8..12] == b"WEBP" {
            Some(ImageType::Webp)
        } else {
            None
        }
    }

    fn image_format(self) -> ImageFormat {
        match self {
            ImageType::Jpeg => ImageFormat::Jpeg,
            ImageType::Png => ImageFormat::Png,
            ImageType::Webp => ImageFormat::WebP,
        }
    }
}

#[derive(Debug, Clone)]
pub struct ValidImage {
    pub kind: ImageType,
    pub width: u32,
    pub height: u32,
    pub sha256: [u8; 32],
    pub data: Bytes,
}

pub fn validate(data: Bytes) -> Result<ValidImage, ApiError> {
    if data.len() > MAX_BYTES {
        return Err(ApiError::ImageTooLarge("Ảnh lớn hơn 1 MB."));
    }
    let kind = ImageType::detect(&data).ok_or(ApiError::NotAnImage)?;
    let (width, height) = ImageReader::with_format(Cursor::new(&data[..]), kind.image_format())
        .into_dimensions()
        .map_err(|_| ApiError::NotAnImage)?;
    if width == 0 || height == 0 {
        return Err(ApiError::NotAnImage);
    }
    if u64::from(width) * u64::from(height) > MAX_PIXELS {
        return Err(ApiError::ImageTooLarge("Ảnh có quá nhiều điểm ảnh."));
    }
    decode(&data, kind).map_err(|_| ApiError::NotAnImage)?;
    let sha256: [u8; 32] = Sha256::digest(&data).into();
    Ok(ValidImage { kind, width, height, sha256, data })
}

pub fn decode(data: &[u8], kind: ImageType) -> image::ImageResult<image::DynamicImage> {
    let mut reader = ImageReader::with_format(Cursor::new(data), kind.image_format());
    let mut limits = Limits::default();
    limits.max_alloc = Some(256 * 1024 * 1024);
    reader.limits(limits);
    reader.decode()
}
```

```rust
use std::collections::{HashMap, VecDeque};
use std::net::{IpAddr, SocketAddr};
use std::sync::Mutex;
use std::time::{Duration, Instant};

use axum::http::{HeaderMap, header};
use ipnet::IpNet;
use subtle::ConstantTimeEq;

use crate::error::ApiError;

pub struct SecretCodeChecker {
    code: Vec<u8>,
    failures: Mutex<HashMap<IpAddr, VecDeque<Instant>>>,
    max_failures: usize,
    window: Duration,
}

impl SecretCodeChecker {
    pub fn new(code: &str) -> Self {
        Self::with_limit(code, 10, Duration::from_secs(600))
    }

    pub fn with_limit(code: &str, max_failures: usize, window: Duration) -> Self {
        Self { code: code.as_bytes().to_vec(), failures: Mutex::new(HashMap::new()), max_failures, window }
    }

    pub fn check(&self, ip: IpAddr, sent: Option<&str>, now: Instant) -> Result<(), ApiError> {
        let mut failures = self.failures.lock().expect("failure counter lock");
        if failures.len() > 10_000 {
            failures.retain(|_, attempts| {
                prune(attempts, now, self.window);
                !attempts.is_empty()
            });
        }
        let attempts = failures.entry(ip).or_default();
        prune(attempts, now, self.window);
        if attempts.len() >= self.max_failures {
            let remaining = self.window.saturating_sub(now.duration_since(attempts[0]));
            return Err(ApiError::TooManyAttempts(remaining.as_secs().max(1)));
        }
        let correct: bool = sent.map(|m| bool::from(m.as_bytes().ct_eq(&self.code))).unwrap_or(false);
        if correct {
            let none_left = attempts.is_empty();
            if none_left {
                failures.remove(&ip);
            }
            Ok(())
        } else {
            attempts.push_back(now);
            Err(ApiError::InvalidCode)
        }
    }
}

fn prune(attempts: &mut VecDeque<Instant>, now: Instant, window: Duration) {
    while attempts.front().is_some_and(|t| now.duration_since(*t) >= window) {
        attempts.pop_front();
    }
}

pub fn client_ip(peer: SocketAddr, headers: &HeaderMap, trusted: &[IpNet]) -> IpAddr {
    let ip = peer.ip();
    if trusted.iter().any(|n| n.contains(&ip)) {
        let forwarded = headers
            .get("x-forwarded-for")
            .and_then(|v| v.to_str().ok())
            .and_then(|s| s.split(',').next_back())
            .and_then(|s| s.trim().parse::<IpAddr>().ok());
        if let Some(x) = forwarded {
            return x;
        }
    }
    ip
}

pub fn code_from_headers(headers: &HeaderMap) -> Option<&str> {
    headers.get(header::AUTHORIZATION)?.to_str().ok()?.strip_prefix("Bearer ")
}
```

```rust
use object_store::{BackoffConfig, ClientOptions, ObjectStore, PutPayload, RetryConfig};
use uuid::Uuid;

use crate::config::{Config, StoreKind};

#[derive(Clone)]
pub struct ImageStore {
    inner: Arc<dyn ObjectStore>,
}

pub fn network_options() -> (ClientOptions, RetryConfig) {
    let options = ClientOptions::new()
        .with_connect_timeout(Duration::from_secs(3))
        .with_timeout(Duration::from_secs(10));
    let retry = RetryConfig {
        backoff: BackoffConfig::default(),
        max_retries: 2,
        retry_timeout: Duration::from_secs(15),
    };
    (options, retry)
}

impl ImageStore {
    pub fn new(inner: Arc<dyn ObjectStore>) -> Self {
        Self { inner }
    }

    pub fn from_config(c: &Config) -> anyhow::Result<Self> {
        let (options, retry) = network_options();
        let inner: Arc<dyn ObjectStore> = match c.store_kind {
            StoreKind::Azure => Arc::new(
                MicrosoftAzureBuilder::from_env()
                    .with_container_name(&c.container)
                    .with_client_options(options)
                    .with_retry(retry)
                    .build()?,
            ),
            StoreKind::S3 => Arc::new(
                AmazonS3Builder::from_env()
                    .with_bucket_name(&c.container)
                    .with_client_options(options)
                    .with_retry(retry)
                    .build()?,
            ),
        };
        Ok(Self::new(inner))
    }

    fn original_path(id: Uuid) -> Path {
        Path::from(format!("original/{id}"))
    }

    fn thumbnail_path(id: Uuid) -> Path {
        Path::from(format!("thumbnail/{id}.avif"))
    }

    pub async fn put_original(&self, id: Uuid, data: Bytes) -> object_store::Result<()> {
        self.inner.put(&Self::original_path(id), PutPayload::from(data)).await.map(|_| ())
    }

    pub async fn get_original(&self, id: Uuid) -> object_store::Result<Option<Bytes>> {
        self.get(&Self::original_path(id)).await
    }

    pub async fn put_thumbnail(&self, id: Uuid, data: Bytes) -> object_store::Result<()> {
        self.inner.put(&Self::thumbnail_path(id), PutPayload::from(data)).await.map(|_| ())
    }

    pub async fn get_thumbnail(&self, id: Uuid) -> object_store::Result<Option<Bytes>> {
        self.get(&Self::thumbnail_path(id)).await
    }

    pub async fn delete_thumbnail(&self, id: Uuid) -> object_store::Result<()> {
        match self.inner.delete(&Self::thumbnail_path(id)).await {
            Ok(()) | Err(object_store::Error::NotFound { .. }) => Ok(()),
            Err(e) => Err(e),
        }
    }

    pub async fn probe(&self) -> object_store::Result<()> {
        match self.inner.head(&Path::from("health/missing")).await {
            Ok(_) | Err(object_store::Error::NotFound { .. }) => Ok(()),
            Err(e) => Err(e),
        }
    }

    async fn get(&self, path: &Path) -> object_store::Result<Option<Bytes>> {
        match self.inner.get(path).await {
            Ok(r) => Ok(Some(r.bytes().await?)),
            Err(object_store::Error::NotFound { .. }) => Ok(None),
            Err(e) => Err(e),
        }
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Mutex};

use bytes::Bytes;
use fast_image_resize::images::Image;
use fast_image_resize::{FilterType, PixelType, ResizeAlg, ResizeOptions, Resizer};
use lru::LruCache;
use tokio::sync::{OnceCell, Semaphore};
use uuid::Uuid;

use crate::image_file::{ImageType, decode};
use crate::image_store::ImageStore;
use crate::error::ApiError;

pub const MAX_EDGE: u32 = 800;
const CACHE_MAX_BYTES: usize = 64 * 1024 * 1024;

pub fn needs_thumbnail(width: u32, height: u32) -> bool {
    width > MAX_EDGE || height > MAX_EDGE
}

pub fn thumbnail_size(width: u32, height: u32) -> (u32, u32) {
    let scale = |edge: u32, long_edge: u32| -> u32 {
        ((u64::from(edge) * u64::from(MAX_EDGE) + u64::from(long_edge) / 2) / u64::from(long_edge)).max(1) as u32
    };
    if width >= height {
        (MAX_EDGE, scale(height, width))
    } else {
        (scale(width, height), MAX_EDGE)
    }
}

pub fn make_thumbnail(original: &[u8], kind: ImageType) -> anyhow::Result<Vec<u8>> {
    let image = decode(original, kind)?.to_rgba8();
    let (width, height) = image.dimensions();
    let (thumb_width, thumb_height) = thumbnail_size(width, height);
    let src = Image::from_vec_u8(width, height, image.into_raw(), PixelType::U8x4)?;
    let mut dst = Image::new(thumb_width, thumb_height, PixelType::U8x4);
    Resizer::new().resize(
        &src,
        &mut dst,
        &ResizeOptions::new().resize_alg(ResizeAlg::Convolution(FilterType::Lanczos3)),
    )?;
    let pixels: Vec<ravif::RGBA8> = dst
        .buffer()
        .chunks_exact(4)
        .map(|p| ravif::RGBA8::new(p[0], p[1], p[2], p[3]))
        .collect();
    let encoded = ravif::Encoder::new()
        .with_quality(60.0)
        .with_alpha_quality(60.0)
        .with_speed(6)
        .encode_rgba(ravif::Img::new(pixels.as_slice(), thumb_width as usize, thumb_height as usize))?;
    Ok(encoded.avif_file)
}

pub struct ThumbnailCache {
    entries: LruCache<Uuid, Bytes>,
    total: usize,
    limit: usize,
}

impl ThumbnailCache {
    pub fn new(limit: usize) -> Self {
        Self { entries: LruCache::unbounded(), total: 0, limit }
    }

    pub fn get(&mut self, id: &Uuid) -> Option<Bytes> {
        self.entries.get(id).cloned()
    }

    pub fn put(&mut self, id: Uuid, data: Bytes) {
        if data.len() > self.limit {
            return;
        }
        if let Some(old) = self.entries.put(id, data.clone()) {
            self.total -= old.len();
        }
        self.total += data.len();
        while self.total > self.limit {
            match self.entries.pop_lru() {
                Some((_, evicted)) => self.total -= evicted.len(),
                None => break,
            }
        }
    }

    pub fn total(&self) -> usize {
        self.total
    }
}

pub struct ServedImage {
    pub data: Bytes,
    pub content_type: &'static str,
}

pub struct ThumbnailService {
    store: ImageStore,
    read_only: bool,
    cache: Mutex<ThumbnailCache>,
    in_flight: Mutex<HashMap<Uuid, Arc<OnceCell<Bytes>>>>,
    one_at_a_time: Semaphore,
    generated: AtomicU64,
}

impl ThumbnailService {
    pub fn new(store: ImageStore, read_only: bool) -> Self {
        Self {
            store,
            read_only,
            cache: Mutex::new(ThumbnailCache::new(CACHE_MAX_BYTES)),
            in_flight: Mutex::new(HashMap::new()),
            one_at_a_time: Semaphore::new(1),
            generated: AtomicU64::new(0),
        }
    }

    pub fn generated_count(&self) -> u64 {
        self.generated.load(Ordering::Relaxed)
    }

    pub async fn get(&self, id: Uuid, original_kind: ImageType, width: u32, height: u32) -> Result<ServedImage, ApiError> {
        if !needs_thumbnail(width, height) {
            let original = self.store.get_original(id).await?.ok_or(ApiError::NotFound)?;
            return Ok(ServedImage { data: original, content_type: original_kind.mime() });
        }
        let cached = self.cache.lock().expect("thumbnail cache lock").get(&id);
        if let Some(b) = cached {
            return Ok(avif(b));
        }
        if let Some(b) = self.store.get_thumbnail(id).await? {
            self.cache.lock().expect("thumbnail cache lock").put(id, b.clone());
            return Ok(avif(b));
        }
        let cell = self
            .in_flight
            .lock()
            .expect("in-flight map lock")
            .entry(id)
            .or_insert_with(|| Arc::new(OnceCell::new()))
            .clone();
        let result = cell.get_or_try_init(|| self.generate(id, original_kind)).await.cloned();
        {
            let mut in_flight = self.in_flight.lock().expect("in-flight map lock");
            if in_flight.get(&id).is_some_and(|x| Arc::ptr_eq(x, &cell)) {
                in_flight.remove(&id);
            }
        }
        Ok(avif(result?))
    }

    async fn generate(&self, id: Uuid, original_kind: ImageType) -> Result<Bytes, ApiError> {
        let _permit = self.one_at_a_time.acquire().await.map_err(|_| ApiError::Unavailable)?;
        let cached = self.cache.lock().expect("thumbnail cache lock").get(&id);
        if let Some(b) = cached {
            return Ok(b);
        }
        let original = self.store.get_original(id).await?.ok_or(ApiError::NotFound)?;
        let data = tokio::task::spawn_blocking(move || make_thumbnail(&original, original_kind))
            .await
            .map_err(|_| ApiError::Unavailable)?
            .map_err(|e| {
                tracing::error!(%id, error = %e, "failed to generate thumbnail");
                ApiError::Unavailable
            })?;
        let data = Bytes::from(data);
        self.generated.fetch_add(1, Ordering::Relaxed);
        self.cache.lock().expect("thumbnail cache lock").put(id, data.clone());
        if !self.read_only {
            if let Err(e) = self.store.put_thumbnail(id, data.clone()).await {
                tracing::warn!(%id, error = %e, "failed to store thumbnail");
            }
        }
        Ok(data)
    }
}

fn avif(data: Bytes) -> ServedImage {
    ServedImage { data, content_type: "image/avif" }
}
```

```rust
pub struct Post {

    pub image_type: String,
    pub image_bytes: i32,

    title: String,
    description: String,
    image_sha256: Vec<u8>,
    image_type: String,
    image_bytes: i32,
    width: i32,
    height: i32,
    created_at: OffsetDateTime,
}

impl From<PostRow> for Post {
    fn from(d: PostRow) -> Self {
        Self {
            id: d.id,
            title: d.title,
            description: d.description,
            image_sha256: hex::encode(d.image_sha256),
            image_type: d.image_type,
            image_bytes: d.image_bytes,
            width: d.width,
            height: d.height,
            created_at: d.created_at,
        }
    }

pub struct NewPost<'a> {
    pub id: Uuid,
    pub idempotency_key: Uuid,
    pub title: &'a str,
    pub description: &'a str,
    pub image: &'a ValidImage,
}

pub enum InsertOutcome {
    Created(Post),
    Existing(Post),
}

pub async fn insert(pool: &PgPool, post: &NewPost<'_>) -> sqlx::Result<InsertOutcome> {
    let row = sqlx::query_as!(
        PostRow,
        r#"INSERT INTO posts (id, idempotency_key, title, description, image_sha256, image_type, image_bytes, width, height)
           VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9)
           ON CONFLICT (idempotency_key) DO NOTHING
           RETURNING id AS "id!", title AS "title!", description AS "description!", image_sha256 AS "image_sha256!",
                     image_type AS "image_type!", image_bytes AS "image_bytes!", width AS "width!", height AS "height!", created_at AS "created_at!""#,
        post.id,
        post.idempotency_key,
        post.title,
        post.description,
        &post.image.sha256[..],
        post.image.kind.mime(),
        post.image.data.len() as i32,
        post.image.width as i32,
        post.image.height as i32,
    )
    .fetch_optional(pool)
    .await?;
    match row {
        Some(d) => Ok(InsertOutcome::Created(d.into())),
        None => {
            let existing = find_by_idempotency_key(pool, post.idempotency_key).await?.ok_or(sqlx::Error::RowNotFound)?;
            Ok(InsertOutcome::Existing(existing))
        }
    }
}

pub async fn get(pool: &PgPool, id: Uuid) -> sqlx::Result<Option<Post>> {
    let d = sqlx::query_as!(
        PostRow,
        "SELECT id, title, description, image_sha256, image_type, image_bytes, width, height, created_at FROM posts WHERE id = $1",
        id
    )
    .fetch_optional(pool)
    .await?;
    Ok(d.map(Post::from))
}

pub async fn find_by_idempotency_key(pool: &PgPool, key: Uuid) -> sqlx::Result<Option<Post>> {
    let d = sqlx::query_as!(
        PostRow,
        "SELECT id, title, description, image_sha256, image_type, image_bytes, width, height, created_at FROM posts WHERE idempotency_key = $1",
        key
    )
    .fetch_optional(pool)
    .await?;
    Ok(d.map(Post::from))
}

pub async fn page(pool: &PgPool, before: Option<Uuid>, limit: i64) -> sqlx::Result<Vec<Post>> {
    let posts = sqlx::query_as!(
        PostRow,
        "SELECT id, title, description, image_sha256, image_type, image_bytes, width, height, created_at FROM posts
         WHERE ($1::uuid IS NULL OR id < $1) ORDER BY id DESC LIMIT $2",
        before,
        limit
    )
    .fetch_all(pool)
    .await?;
    Ok(posts.into_iter().map(Post::from).collect())
}
```

```rust
pub fn spawn_migrations(state: Arc<AppState>) -> tokio::task::JoinHandle<()> {

                    tracing::info!("database schema ready");
                    break;

                Err(e) => {
                    tracing::warn!(error = %e, "database schema not ready, retrying in 2 seconds");
                    tokio::time::sleep(Duration::from_secs(2)).await;
                }
            }
        }
    })
```

```rust
    pub before: Option<Uuid>,
    pub limit: Option<i64>,

    pub next: Option<Uuid>,

#[utoipa::path(
    get,
    path = "/v1/posts",
    params(PageQuery),
    responses(
        (status = 200, body = PostPage),
        (status = 422, body = ErrorBody),
        (status = 503, body = ErrorBody)
    )
)]
pub async fn list_posts(
    State(state): State<Arc<AppState>>,
    q: Result<Query<PageQuery>, QueryRejection>,
) -> Result<Json<PostPage>, ApiError> {
    let Query(q) = q.map_err(|_| ApiError::InvalidInput("Tham số không hợp lệ.".into()))?;
    let limit = q.limit.unwrap_or(24);
    if !(1..=60).contains(&limit) {
        return Err(ApiError::InvalidInput("Số bài mỗi trang phải từ 1 đến 60.".into()));
    }
    let mut posts = db::page(&state.pool, q.before, limit + 1).await?;
    let next = if posts.len() as i64 > limit {
        posts.truncate(limit as usize);
        posts.last().map(|b| b.id)
    } else {
        None
    };
    Ok(Json(PostPage { posts, next }))
}

    let kind = image_type_of(&post)?;
    let out = state.thumbnails.get(post.id, kind, post.width as u32, post.height as u32).await?;
    Ok(image_response(out.data, out.content_type, format!("{}-thumbnail", post.image_sha256)))
}

async fn find_post(state: &AppState, id: Result<Path<Uuid>, PathRejection>) -> Result<Post, ApiError> {
    let Path(id) = id.map_err(|_| ApiError::NotFound)?;
    db::get(&state.pool, id).await?.ok_or(ApiError::NotFound)
}

fn image_type_of(post: &Post) -> Result<ImageType, ApiError> {
    ImageType::from_mime(&post.image_type).ok_or(ApiError::Unavailable)
}

fn image_response(data: Bytes, content_type: &'static str, etag: String) -> Response {
    (
        [
            (header::CONTENT_TYPE, content_type.to_string()),
            (header::ETAG, format!("\"{etag}\"")),
            (header::CACHE_CONTROL, "public, max-age=31536000, immutable".to_string()),
        ],
        data,
    )
        .into_response()
```

```rust
use std::net::SocketAddr;
use std::time::Instant;

use axum::extract::ConnectInfo;
use axum::extract::multipart::{Multipart, MultipartError, MultipartRejection};
use axum::http::{HeaderMap, StatusCode};

use crate::image_file;
use crate::db::{NewPost, InsertOutcome};
use crate::{secret_code, text};

#[derive(ToSchema)]
#[allow(dead_code)]
pub struct CreatePostForm {
    idempotency_key: Uuid,
    title: String,
    description: String,
    #[schema(value_type = String, format = Binary)]
    image: Vec<u8>,
}

struct PostForm {
    idempotency_key: Uuid,
    title: String,
    description: String,
    image: Bytes,
}

#[utoipa::path(
    post,
    path = "/v1/posts",
    request_body(content = CreatePostForm, content_type = "multipart/form-data"),
    security(("secret_code" = [])),
    responses(
        (status = 201, body = Post),
        (status = 200, body = Post),
        (status = 401, body = ErrorBody),
        (status = 413, body = ErrorBody),
        (status = 415, body = ErrorBody),
        (status = 422, body = ErrorBody),
        (status = 429, body = ErrorBody),
        (status = 503, body = ErrorBody)
    )
)]
pub async fn create_post(
    State(state): State<Arc<AppState>>,
    ConnectInfo(peer): ConnectInfo<SocketAddr>,
    headers: HeaderMap,
    multipart: Result<Multipart, MultipartRejection>,
) -> Result<(StatusCode, Json<Post>), ApiError> {
    if state.config.read_only {
        return Err(ApiError::ReadOnly);
    }
    let ip = secret_code::client_ip(peer, &headers, &state.config.trusted_proxies);
    state.secret_code.check(ip, secret_code::code_from_headers(&headers), Instant::now())?;
    let multipart = multipart.map_err(|_| ApiError::InvalidInput("Cần gửi multipart/form-data.".into()))?;
    let form = read_form(multipart).await?;
    if let Some(existing) = db::find_by_idempotency_key(&state.pool, form.idempotency_key).await? {
        return Ok((StatusCode::OK, Json(existing)));
    }
    let title = text::title(&form.title)?;
    let description = text::description(&form.description)?;
    let valid = tokio::task::spawn_blocking(move || image_file::validate(form.image))
        .await
        .map_err(|_| ApiError::Unavailable)??;
    let id = Uuid::now_v7();
    state.store.put_original(id, valid.data.clone()).await?;
    let new_post = NewPost { id, idempotency_key: form.idempotency_key, title: &title, description: &description, image: &valid };
    match db::insert(&state.pool, &new_post).await? {
        InsertOutcome::Created(b) => Ok((StatusCode::CREATED, Json(b))),
        InsertOutcome::Existing(b) => Ok((StatusCode::OK, Json(b))),
    }
}

async fn read_form(mut m: Multipart) -> Result<PostForm, ApiError> {
    let (mut key, mut title, mut description, mut image) = (None, None, None, None);
    while let Some(field) = m.next_field().await.map_err(multipart_error)? {
        match field.name() {
            Some("idempotency_key") => key = Some(field.text().await.map_err(multipart_error)?),
            Some("title") => title = Some(field.text().await.map_err(multipart_error)?),
            Some("description") => description = Some(field.text().await.map_err(multipart_error)?),
            Some("image") => image = Some(field.bytes().await.map_err(multipart_error)?),
            _ => {}
        }
    }
    let idempotency_key = key
        .as_deref()
        .and_then(|s| Uuid::parse_str(s.trim()).ok())
        .ok_or_else(|| ApiError::InvalidInput("Thiếu hoặc sai idempotency_key.".into()))?;
    Ok(PostForm {
        idempotency_key,
        title: title.ok_or_else(|| ApiError::InvalidInput("Thiếu tiêu đề.".into()))?,
        description: description.unwrap_or_default(),
        image: image.ok_or_else(|| ApiError::InvalidInput("Thiếu ảnh.".into()))?,
    })
}

fn multipart_error(e: MultipartError) -> ApiError {
    if e.status() == StatusCode::PAYLOAD_TOO_LARGE {
        ApiError::ImageTooLarge("Ảnh lớn hơn 1 MB.")
    } else {
        ApiError::InvalidInput("Dữ liệu gửi lên không đọc được.".into())
    }
}
```

```rust
mod common;

use std::io::Cursor;
use std::time::{Duration, Instant};

use common::{TestStore, TEST_CODE, start, submit_post, writable_store};
use image::{DynamicImage, ImageFormat, RgbImage};
use uuid::Uuid;

fn script_image(i: u32) -> Vec<u8> {
    let image = DynamicImage::ImageRgb8(RgbImage::from_fn(160, 120, |x, y| {
        let n = x.wrapping_mul(2_654_435_761).wrapping_add(y.wrapping_mul(40_503)).wrapping_add(i.wrapping_mul(97));
        image::Rgb([n as u8, (n >> 8) as u8, (n >> 16) as u8])
    }));
    let mut out = Cursor::new(Vec::new());
    image.write_to(&mut out, ImageFormat::Png).unwrap();
    out.into_inner()
}

#[tokio::test(flavor = "multi_thread")]
#[ignore = "chạy riêng: cargo test --test load -- --ignored --nocapture"]
async fn one_post_per_second_for_five_minutes_uses_under_ten_percent_of_a_core() {
    let app = start(writable_store(TestStore::Seaweed), false).await;
    let c = reqwest::Client::new();
    let cpu = cpu_time::ProcessTime::now();
    let started = Instant::now();
    for i in 0..300 {
        let tick = Instant::now();
        let r = submit_post(&c, &app.url, TEST_CODE, Uuid::now_v7(), &format!("Tải {i}"), script_image(i)).await;
        assert_eq!(r.status(), 201);
        tokio::time::sleep(Duration::from_secs(1).saturating_sub(tick.elapsed())).await;
    }
    let ratio = cpu.elapsed().as_secs_f64() / started.elapsed().as_secs_f64();
    println!("cpu_ratio={ratio:.3}");
    assert!(ratio <= 0.10, "CPU {ratio:.3} vượt 10% một nhân");
}
```
